# AFT200 토크→힘 간섭 보정

근거: Shin et al., *Applied Sciences* 2025, 15(3), 1510,
[DOI](https://doi.org/10.3390/app15031510),
[최종 출판 PDF](https://mdpi-res.com/d_attachment/applsci/applsci-15-01510/article_deploy/applsci-15-01510.pdf).
최종 PDF의 §2.3, 식 (6), (8)을 확인했다. AFT200과 Robotiq **3-Finger** 실험이며
2F-85용 공통 보정 계수를 제공하는 논문은 아니다. 기존 논문의 성능 개선율을
우리 장치의 예상 정확도로 사용하지 않는다.

## 이번 구현 범위

최종 목표는 총중량 일치가 아니라 **물체만의 6축 렌치가 PIVOT의 측정식과
잔차·불확실성 범위 안에서 일치하고 부품별 밀도가 복원되는 것**이다.
힘 검증만 통과한 K를 최종 밀도 실험의 교정으로 승격하지 않는다.

최종 검증에서는 (1) 원점·축·부호·중력 방향 일치, (2) 알려진 질량 및 센서 기준
무게중심을 가진 기준 물체의 힘/토크 벡터 잔차, (3) 보정 후 반복 산포와 계수
불확실성, (4) 미사용 자세·파지점에서 부품별 밀도 절대오차와 신뢰구간을 평가한다.
실물 부품별 정확도를 채점하려면 별도로 확인한 부품 질량과 부피가 필요하다.
기존 각도 3°/파지점 10 mm의 1σ는 계속 별도 오차원으로 고려한다.

시뮬레이션의 기본 잡음 0.10 N/0.003 N·m를 실물 보정 후 정확도로 가정하지 않는다.
간섭 제거는 바이어스를 줄여도 토크 잡음을 힘 채널로 전파할 수 있다. 예를 들어
계수 크기 10 /m와 토크 불확실성 0.02 N·m의 곱은 힘 불확실성 0.2 N이다.
실제 달성한 공분산으로 밀도 오차를 평가하고, 부족하면 측정 자세의 정보량,
장착/센서 교정 또는 측정 경로의 정밀도를 개선한다.

논문의 6개 비대각 계수를 같은 자세의 빈 상태/기준 하중 차분으로 식별한다.
이는 논문의 토크→힘 모형을 적용한 변형이며, 공구 CoM·베이스 기울기·간섭 계수를
동시에 맞추는 원문 식 (10)의 11변수 비선형 교정 전체를 재현하지는 않는다.
부품별 밀도 추정의 미지 질량을 정답으로 넣는 것이 아니라 별도의 **교정용 표준
질량**을 사용한다. 별도 검증 기록의 질량은 계수 적합에 사용하지 않는다.

```text
K = [[0, kxy, kxz], [kyx, 0, kyz], [kzx, kzy, 0]]  # 계수 단위 1/m
F_measured = F_true + bias_F + K @ torque_true
torque_measured = torque_true + bias_T

delta = loaded - (empty_before + empty_after)/2
K @ delta_torque ≈ delta_force - mass_reference * 9.81 * g_sensor
corrected_force = delta_force - K @ delta_torque
corrected_torque = delta_torque
```

같은 개구·자세·바이어스에서 차분하므로 공구 중력과 고정 영점이 상쇄된다.
전후 빈 값 변화가 힘 0.5 N/토크 0.02 N·m보다 크면 주기를 거부한다.
전후 평균은 기준의 중간값이며 시간 드리프트를 선형이라고 가정해 적합하지 않는다.
물체 토크를 0으로 만들거나 원하는 질량이 나오도록 힘 크기만 재조정하지 않는다.

논문 모형의 대각 0 및 힘→토크 간섭 0은 **검증할 가정**이다. 센서 축과 장착 축이
다르면 먼저 축 정렬을 검증해야 한다. 현재 기록의 g_sensor는 FK와 base의 −Z
중력 가정에서 계산된다. 실제 base 기울기/센서 축 정렬은 별도 확인이 필요하다.
이 가정이 틀리면 K가 기하 오차를 흡수할 수 있으므로 힘 검증 통과만으로 전체
6축 정확도나 전 방향 교정 완료를 선언하지 않는다.

## 실물 수집 순서

1. 현재 그리퍼 상태 확인 후 팔 이동 없이 시작한다. 영점/장착/재연결이 바뀌면
   새 ft-session-id를 사용한다. 충분히 예열하고 센서 영점은 주기 중 바꾸지 않는다.
2. 기준 물병을 잡았을 때의 실제 위치 카운트를 확인한다. 물병 제거 후 같은
   카운트의 빈 개구를 맞춘다. 한 번만 기록해 두고 다른 자세에 재사용하지 않는다.
   Robotiq 링크 구조 때문에 같은 카운트가 완전히 같은 손가락 형상을 보장하지는 않는다.
3. 같은 팔 자세에서 **빈 기준 → 물병 파지 → 제거 후 같은 개구의 빈 복귀**를
   각각 기록한다. 실제 개구 차이 ≤3카운트, 팔 자세 차이 ≤0.1°를 검사한다.
   1주기는 20분 이내여야 하며 구동 완료 후 안정된 기록만 사용한다.
4. 파지점/방향을 바꿔 충분히 독립적인 토크를 만든다. 같은 한 자세의 병 높이만
   바꾸면 모든 6개 계수를 식별하지 못할 수 있다. 행렬 조건수 ≤100과 각 힘 축의
   두 입력 토크에 대한 최소 특이값/√N ≥0.05 N·m를 검사한다. 이는 조정 가능한
   공학적 정보량 기준이며 센서 분해능·정확도·1σ를 뜻하지 않는다.
5. 식별과 별도로 검증용 주기를 확보한다. 각각 최소 3주기는 입력 하한일 뿐,
   실제로는 여러 토크 방향이 필요하다. 다른 파지점과 가능하면 다른 기준 질량도
   포함해 보정 전후 힘 벡터 잔차·합력 질량·중력 투영 질량을 평가한다.

팔 이동은 기존 self collision, wrist 케이블 원통, 책상, optical table,
왼쪽 로봇 오른쪽 지지대를 포함한 전체 경로 검사를 통과해야 한다.
추가 장애물 형상은 아직 미확인이므로 이 도구에서 자동 이동하지 않는다.

기록은 기존 `setup/local_ft_check.sh --record`를 사용한다. 필요한 옵션은
`--gripper-status-file /tmp/lamp_foundationpose_live/hardware.json`, 새 `--ft-session-id`,
`--load-state empty|loaded`, `--configuration-id`, `--samples 100 --blocks 10 --settle-s 5`다.
각 상태를 사용자 확인 후 기록하며 `--output`은 서로 다른 절대 경로로 지정한다.

## 오프라인 실행

manifest JSON은 파일 경로를 manifest 위치 기준으로 해석한다.
아래 예시는 구조만 나타내며 train/validation 각각 실제 주기를 최소 3개 기재한다.
질량 단위는 kg이다.

```json
{
  "train": [
    {"empty_before": "e1.json", "loaded": "l1.json", "empty_after": "r1.json", "reference_mass_kg": 1.332}
  ],
  "validation": [
    {"empty_before": "e4.json", "loaded": "l4.json", "empty_after": "r4.json", "reference_mass_kg": 0.541}
  ]
}
```

my_work에서 실행:

```bash
../robot_learning/scripts/run_drake_env.sh python -B ../tools/calibrate_ft_crosstalk.py \
  --manifest outputs/crosstalk_manifest.json --output outputs/crosstalk_result.json
```

기존 기록 검사기를 재사용하며, 세션/센서/FK 지문, 원시 평균 일치, 안정화,
실제 개구, 주기 순서를 확인한다. 식별/검증 간 파일 내용 중복을 거부한다.
축별 정보량이 부족하면 부분 계수를 임의로 채우지 않고 matrix=null로 반환한다.
결과에 기준값·보정된 6축·잔차와 질량 절대오차를 보존한다. 출력은 덮어쓰지 않는다.

`force_validation_passed`는 해당 기록 범위의 힘 잔차 검사다. 토크 정확도와
계수 추정 불확실성이 검증되지 않았으므로 `calibration_valid=false`,
`uncertainty_calibrated=false`, `estimator_reply=null`을 유지한다.
활성 영점/통합 UI에는 자동 적용하지 않는다. 후속 연결 시 센서 공분산도
J=[[I,−K],[0,I]]로 변환하고 계수 추정 불확실성을 추가해야 한다.

## 무엇을 자를 것인가 (우선순위)

1. **같은 말을 두 번 하는 곳.** 논문이 Method 에서 설명한 것을 Experiments 도입부에서
   다시 설명하는 대목이 많다. 뒤엣것을 지운다.
2. **자기 설명적 문장.** "이 절에서는 ~을 설명한다", "다음으로 ~을 살펴본다" 류 전부 삭제.
3. **한 문단에 한 주장.** 같은 주장을 각도만 바꿔 반복하는 문장을 합친다.
4. **표가 이미 말하는 수치의 산문 재서술.** 표에 있는 숫자를 본문에서 다시 나열하지 않는다.
   본문에는 **표가 말하지 못하는 해석**만 남긴다.
5. **긴 배경 설명.** 독자가 아는 것(3DGS 가 무엇인지, D-최적성이 무엇인지)은 한 구로 줄인다.
6. **증명.** 짧은 것은 남기고, 긴 IEEEproof 는 핵심 한 줄로 줄이거나 각주로 내린다.

## 절대로 자르면 안 되는 것 (하나라도 사라지면 실패)

- **정직성 단서 전부.** 특히:
  - 밀도 오차 = 질량 오차 (1.7e-16) 불변성 각주
  - 2link 에서 ours ≡ single 이라는 사실
  - single 의 실패는 점오차가 아니라 반폭(2.6/28.7/42.5%)에 있다는 서술
  - 질량은 부피 오차에 **엄밀히** 불변하지 않다는 것 (30%에서 3~6%)
  - 부피 오차가 **라운드 수**를 늘린다는 것 (1→7, 3/8 미수렴)
  - 관절한계 위반 열이 **해석적으로 죽은 열**이라는 것
  - 62 mm 일화를 재현했다고 쓰지 않는 것 (테이블 33.1 mm vs 로봇팔 93.8 mm 구분)
  - Exp E 가 **시뮬-시뮬 대리 검증**이라는 것, 기준이 GT 밀도 plant 라는 것
  - 2link RELEASE 가 구조적으로 밀도에 둔감하다는 것
  - 관성 텐서는 준정적으로 식별 불가능하며 **유도량**이라는 것
  - 물체가 적어 통계적 유의성을 주장할 수 없다는 것
  - 실물 결과가 없다는 것 (`\Pending`, `\rev{}` 전부 유지)
- **Kumar et al. 2019 을 구분해 인용하는 문장.** (놓친 선행연구 지적을 막는 유일한 방어)
- **삼면체 3자세의 정정된 논증** (rank 가 아니라 등방성·조건수·자유 SO(3)).
- **정보 손실 0.0% / 최대 관절토크 −39.9%** 수치.
- **사용자 개입 표현**: "추가되는 개입은 한 곳" (never "개입 지점이 한 곳").
- 모든 정리·따름정리의 **진술**. (증명은 줄여도 되지만 진술은 남긴다)
- `% [번역]` 한국어 주석 관행. **문단을 합치면 번역 주석도 합쳐서 갱신할 것.**

## 형식 규칙
- "excitation", "orbit" 금지. "PIVoT" 표기.
- 남긴 문단마다 `% [번역]` 주석이 대응해야 한다. 문단을 지우면 그 번역 주석도 지운다.
- 삭제한 내용을 `%` 주석으로 파일 하단에 보관하지 **말 것** — 파일만 커지고 분량은 안 준다.
  꼭 남겨야 하면 별도 파일 `CUTS.md` 에 옮긴다.
- `\label` 을 지우지 말 것. 다른 파일이 `\ref` 한다.
- 빌드가 깨지면 안 된다:
  `PATH=~/miniconda3/envs/test/bin:$PATH tectonic -X compile main.tex --outdir build`

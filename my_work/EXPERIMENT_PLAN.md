## 지금 당장 — 장비 없이 되는 것

### E1. n-link 검증 (p=5, p=6)  — **진행 중**

**채우는 곳**: IV-C (Scaling), Fig. 3

```
   현재  p=2  1 라운드 (4/4)     하한 1  ✓
         p=3  2 라운드 (4/4)     하한 2  ✓
         p=4 34 라운드 (3/4)     되말림 시작
         p=5  진행 중 (예산 120)
         p=6  대기  (p=5 결과 보고 예산 결정)
```

**닫힌 루프는 p=2..6, 진단(SNR·상수 C·모멘트팔)은 p=2..8.**
p=7,8 은 닫힌 루프로 돌려도 새 현상이 없고 (최소 간격이 4.6mm 로 포화) 비용만
크다. **Contribution 4번 문구를 "to six links" 또는 "diagnostic sweep to
eight links" 로 맞춰야 한다.**

### E2. 재구성 정확도 실측  — **반나절**

**채우는 곳**: IV-A 의 "Reconstruction accuracy" 문단

```
   커스텀 2·3-link 는 CAD 정답이 있다.
        스캔 부피  vs  CAD 부피    ->  "우리 재구성의 부피 오차는 X %"
        스캔 도심  vs  CAD 도심    ->  "도심 오차는 Y mm"
   그리고 이미 잰 민감도와 짝지어 쓴다
        부피 10 % -> 질량 6 % ,  도심 1 mm -> 질량 2.4 %
```

**baseline 비교는 하지 않는다.** 재구성은 우리 기여가 아니고, 비교하면
"왜 더 좋은 걸 안 썼나" 를 자초한다. 목적은 **공정성** — 모든 baseline 이
같은 재구성을 쓴다는 것을 보이는 것.

### E3. 시뮬레이션 baseline 3종  — **하루**

**채우는 곳**: IV-B 의 표

```
   강체 변형        물체를 덩어리 하나로 취급
   단일 자세 변형    형상을 안 바꾸고 반복 측정만
   WLS 변형         오차변수 보정 없이
```

**앞의 둘이 특히 중요하다** — Cor.2 가 *"강체는 rank 4 를 못 넘는다"* 고
예측한 그 실패를 직접 보이는 자리다. **이론과 실험이 맞물리는 가장 강한 그림**
이고, 우리 코드 안에서 스위치 하나로 된다.

## 센서 도착 후 — 실물

### E5. 실물 측정 4개  — **순서가 중요하다**

**채우는 곳**: IV-D, Tab. II, Fig. 1

```
   1순위  custom 2-link   미지수 3, 1 라운드. 가장 단순 -> 파이프라인 디버깅
   2순위  custom 3-link   미지수 5, 2 라운드. **이론 검증의 핵심**
   3순위  desk lamp       분해할 때 **배수법으로 부위 부피도 실측**
   4순위  laptop          기지 추 50 g 차분
```

램프·노트북을 먼저 하면 **오차가 재구성 탓인지 코드 탓인지 못 가린다.**
CAD 정답이 있는 물체에서 코드를 먼저 검증하는 것이 순서다.

> **최소 생존선**: 일정이 밀리면 **2-link 하나만이라도** 돌린다. 1 라운드면
> 끝나고, "이론 예측이 실물에서 맞는다" 는 한 점은 확보된다.

### E6. 반복성  — **E5 에 끼워 넣는다**

사람이 손으로 관절각을 맞추는 절차다. **같은 물체를 3~5 번 돌려 추정이
일관되는지** 보인다. 안 하면 *"운이 좋았던 것 아닌가"* 가 남는다.
추가 비용은 세션 몇 번뿐이다.

### E7. 소요 시간 로그  — **공짜**

*"한 라운드 1~2 분"* 이라고 쓸 텐데 실측값이 있어야 한다.
**사람 개입 시간과 로봇 이동 시간을 나눠서** 기록하면 *"최소 개입"* 주장의
근거가 된다. 코드가 이미 라운드마다 시각을 찍으므로 로그만 남기면 된다.

### E8. 시뮬레이터 재생 검증  ★ **가장 큰 구멍**

**채우는 곳**: IV-D, Fig. 4

논문이 "sim-ready", "faithful in dynamics" 를 주장하는데 지금 재는 것은
**질량 오차뿐**이다. 리뷰어가 반드시 묻는다 — *"질량이 맞으면 시뮬레이션이
맞는다는 보장이 있나?"*

```
   ① 실물을 넘어뜨리거나 떨어뜨려 영상 촬영 (초기조건을 기록)
   ② 같은 초기조건으로 시뮬레이션 재생
        · 우리 추정 밀도
        · VLM baseline 밀도
        · 균일 밀도
   ③ 궤적을 겹쳐 그린다
```

**이것이 "sim-ready" 라는 단어를 정당화하는 유일한 실험이다.**
그림 하나로 강하게 전달되고, 없으면 제목의 절반이 근거를 잃는다.

> **간소화 가능**: 관절체를 넘어뜨리는 것이 어려우면, **관절을 놓았을 때
> 중력으로 처지는 궤적**을 비교해도 된다. 마찰 유지 관절이라 천천히 처지므로
> 촬영과 재현이 쉽다.

## 2. 본편 6장

### T1. 왜 형상을 바꿔야 하는가
**주제** Theoretical Contribution ①
**부제** — 형상을 고정하면 부위 4개까지가 천장

```
저울과 균형점        총질량 1 + 무게중심 3  =  4개
미지수               부위 수만큼

rank M(θ)  ≤  1 + rank C(θ)  ≤  1 + min(3, P)  =  4
                    방향 몇 개든, 몇 번 반복하든 무관

따름정리 2   부위 5개 이상 강체 조립품  →  사전지식 없이 식별 불가
             Sum of Its Parts   부위 균질 가정
             Scalable Real2Sim  단일 페이로드 모형
             전부 rank 4 때문

정리 2   null M(θ) = { u : Σ uᵢVᵢ = 0,  Σ uᵢVᵢcᵢ(θ) = 0 }
         총질량과 무게중심을 보존하는 재배치는 안 보인다
```

**증명** — 화면 아래쪽 작게, 또는 애니메이션 없이 한 번에

```
M(θ) = g² [ (3/σf²)·v vᵀ  +  (2/σt²)·C(θ)ᵀC(θ) ]        직교 삼면체

rank(v vᵀ)  = 1                    v 는 벡터 하나
rank(CᵀC)  ≤ rank C ≤ min(3, P)    C 가 3행짜리
──────────────────────────────────────────────────
rank M(θ)  ≤ 1 + min(3, P) = 4     방향 개수·반복과 무관   ∎

uᵀMu = 0  ⇔  a(vᵀu)² + b‖Cu‖² = 0,   a, b > 0
          ⇔  vᵀu = 0  이고  Cu = 0
          ⇔  Σ uᵢVᵢ = 0  이고  Σ uᵢVᵢcᵢ(θ) = 0            ∎
```

**그림** `fig_nullspace.png` — 하단 전체 폭

**말할 것**
> 아령을 저울에 올려도 가벼운 봉에 무거운 원판인지 그 반대인지는 끝내 알 수
> 없습니다. 숫자 네 개를 얻었는데 미지수가 더 많기 때문입니다. 그림에서
> 링크1을 23퍼센트, 링크2를 29퍼센트 바꿨는데 총질량과 무게중심이 소수점까지
> 같습니다. 센서에게는 완전히 같은 물체입니다. 관절 하나를 접으면 그제야 2.1
> 밀리미터 갈라집니다. **그 2.1밀리미터가 신호의 전부입니다.**
> 그리고 이 결과가 남의 연구를 설명해 줍니다. 세 편이 각각 다른 사전지식을
> 썼는데, 취향이 아니라 물리적 필연이었다는 걸 보입니다.

### T2. 새로 주장하는 것
**주제** Theoretical Contribution ②
**부제** — 필요 자세 수가 형상만으로 계산되고, 실물이 등호로 맞는다

```
R ≥ ⌈(P−1)/3⌉        링크 p개 + 힌지 → P = 2p−1 → R ≥ ⌈(2p−2)/3⌉

M 에 밀도 ρ 없음      센서 대기 전에 계산됨
```

**증명**

```
M_R = Σᵣ M(θᵣ) = a·R·v vᵀ  +  b·Σᵣ C(θᵣ)ᵀC(θᵣ)
                      ↑
               v 에 θ 가 없다 — R 번 더해도 rank 는 1

rank M_R ≤ rank(v vᵀ) + Σᵣ rank C(θᵣ) ≤ 1 + min(3R, P)

식별 가능 ⇔ rank M_R = P
        ⇒ P ≤ 1 + 3R  ⇒  R ≥ ⌈(P−1)/3⌉                  ∎
```

| 물체 | 미지수 | 한 자세 rank | 하한 R | 실제 R |
| --- | ---: | ---: | ---: | ---: |
| 2-link 커스텀 | 3 | 3 | 1 | **1** |
| 3-link 커스텀 | 5 | **4 (천장)** | 2 | **2** |
| desk lamp | 3 | 3 | 1 | 2 |

```
we recall    Lemma 1 · Prop 1    닫힌 형태, rank 4 천장
                                 Atkeson · An · Hollerbach 1986

we show      Cor. 2              고전 한계  →  부위 개수 상한
             Prop. 3             자세 수 하한, 실물이 등호
             Cor. 1 귀결         정밀도를 측정 전에 예측
             Remark              하한은 덧셈, 실제 필요는 곱셈
```

**그림** 없음

**말할 것**
> 3-link 가 핵심 사례입니다. 미지수가 다섯인데 한 자세로는 넷이 천장이니
> 최소 두 자세가 반드시 필요하고, 실제로 정확히 두 라운드에 끝납니다.
> 예측한 숫자가 실물에서 등호로 맞는 것이 이 주장의 힘입니다.
> 정적 측정이 질량과 무게중심만 준다는 건 1986년 교과서 내용입니다. 새 발견인
> 척 쓰면 리뷰어가 즉시 잡습니다. 우리 것은 그걸 밀도로 다시 썼을 때 나오는
> 귀결입니다.

### B6. 증명 전문
**부제** — 네 줄짜리 유도

```
측정 모형
   y = A(θ, ĝ) ρ + ε        A = g [   ĝ vᵀ    ]   힘 3줄
                                  [ −[ĝ]ₓC(θ) ]   토크 3줄
   R = blkdiag(σf² I₃,  σt² I₃)

① 닫힌 형태        M(θ) = Σₖ Aₖᵀ R⁻¹ Aₖ
   힘 블록          (g ĝvᵀ)ᵀ(g ĝvᵀ)/σf² = g²/σf² · v vᵀ        ĝᵀĝ = 1
   토크 블록        (g[ĝ]ₓC)ᵀ(g[ĝ]ₓC)/σt² = g²/σt² · Cᵀ(I−ĝĝᵀ)C
   합               M = g²[ (K/σf²) v vᵀ + (1/σt²) Cᵀ(K I − Σ ĝĝᵀ) C ]

② 삼면체 불변       직교정규 삼면체면 Σ ĝĝᵀ = I
   M(θ) = g²[ (3/σf²) v vᵀ + (2/σt²) CᵀC ]
   → 삼면체를 통째로 돌려도 불변.  그리고 M 에 ρ 가 없다

③ rank 천장         rank(v vᵀ) = 1,   rank(CᵀC) ≤ rank C ≤ min(3,P)
   rank M(θ) ≤ 1 + min(3, P) = 4                                  ∎

④ 영공간            uᵀMu = 0 ⇔ a(vᵀu)² + b‖Cu‖² = 0,  a,b > 0
                            ⇔ vᵀu = 0 이고 Cu = 0
                            ⇔ Σ uᵢVᵢ = 0 이고 Σ uᵢVᵢcᵢ(θ) = 0     ∎

⑤ 라운드 하한       M_R = a·R·v vᵀ + b·Σᵣ C(θᵣ)ᵀC(θᵣ)
                    v 에 θ 가 없다 → R 번 더해도 힘 몫은 rank 1
   rank M_R ≤ 1 + min(3R, P),   식별 ⇔ rank M_R = P
   ⇒ P ≤ 1 + 3R ⇒ R ≥ ⌈(P−1)/3⌉,   사슬이면 ⌈(2p−2)/3⌉          ∎

⑥ 채널 분리 (Remark)
   F = −g(vᵀρ)ĝ  에 θ 없음  ⇒  ∂F/∂θ = 0       각도 오차는 토크만 오염
   ρ ↦ F 의 행렬 = −g ĝvᵀ, rank 1              힘은 vᵀρ 하나만 결정
   ⇒ 부위를 구별하는 부분공간 = 각도 오차가 오염하는 부분공간      ∎
```

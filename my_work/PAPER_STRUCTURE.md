## III. Method (2.1쪽)

### A. Problem Formulation (0.35쪽)

측정 모형과 기호. `y = A(θ,ĝ)ρ + ε`, `v` 와 `C(θ)` 정의.
저울 1회로 사전분포 초기화. **형상은 주어진 것으로 두되 가정을 정량화**한다
(도심 1mm → 질량 2.4%, 부피 10% → 6%). 주 지표는 질량·CoM·관성이고 밀도는
파생값 `m/V`.  ✅ 작성됨

### B. Articulated Asset Reconstruction (0.2쪽)

RORA 기반. metric scale 은 RGB-D + 기준 마커. 힌지처럼 저울에는 올라가지만
재구성에 없는 부품은 **미지수로 편입**해야 함(빼면 23% 치우침). 파지점
어긋남 δ 는 선형 미지수 3개.  ✅ 작성됨

### C. What Quasi-Static Sensing Can Determine (0.65쪽) ★ 이론

| | 내용 |
| --- | --- |
| Lemma 1 | 정보행렬의 닫힌 형태. 삼면체 회전 불변 |
| Cor. 1 | 설계공간이 `Θ` 로 축소. 힘 채널은 저울과 중복. `M` 에 ρ 없음 |
| Prop. 1 | `rank M(θ) ≤ 1 + rank C(θ) ≤ 4` — 방향 개수·배치 무관 |
| Cor. 2 | 강체는 영원히 rank 4 → **부위 4개 초과면 형상 변경이 필요조건** |
| Prop. 2 | 영공간 = 질량·1차모멘트 보존 재배치 |
| Prop. 3 | `R ≥ ⌈(P−1)/3⌉`, 사슬은 `⌈(2p−2)/3⌉` |
| Remark | **필요조건이지 충분조건이 아니다.** 실제 라운드 수는 조건수가 정한다 |

**표현 수위**: Lemma 1 과 Prop 1 은 고전 사실(정적 측정은 질량·무게중심만)을
밀도 매개화로 옮긴 것이므로 *"we recall"* 로 쓴다. 새로 주장하는 것은 Prop 3
과 재매개화가 만드는 "부위 개수의 상한" 이라는 귀결.  ✅ 작성됨

**Fig. 2**: 영공간 그림 — 총질량·무게중심을 보존하는 재배치가 한 형상에서
안 보이다가 접으면 보이는 것을 3부위 도식으로. *아직 없음.*

### D. Estimation under Angle Uncertainty (0.5쪽)

각도는 명령이 아니라 **측정**이므로 회귀행렬 자체가 오염된다(EIV).
WLS 는 점근 편향 → 각도 보정량 δ_r 을 미지수로 함께 푸는 TLS.
사후 갱신은 `R_eff = R + JΣ_θJᵀ`.

> **여기에 이번에 찾은 것을 한 문단으로 넣는다.**
> 미지수로 함께 푼 것은 잔차를 잴 때도 반영해야 한다. TLS 가 맞춘 모형은
> `y ≈ A(θ+δ)ρ` 인데 잔차를 `y − A(θ)ρ` 로 재면 보정량이 통째로 잔차로
> 잡혀 팽창이 **79배**까지 뛰고, 추정이 이미 목표를 넘었는데도 정지 조건이
> 만족되지 않는다. 오차변수 추정기와 잔차 기반 정지 조건을 함께 쓸 때
> 구조적으로 빠지는 함정이다.  ⬜ **추가 필요**

정지 조건: 부위에 대한 95% 상대 반폭, 잔차로 팽창. 힌지 같은 nuisance 는 제외.

### E. Active Configuration Selection (0.3쪽)

D-최적. Cor. 1 에 의해 중력 삼면체가 목적함수에서 빠지므로 **관절각만** 탐색.
연속 최적화(다중 시작). 그리고 고전 설계에 없는 것 — **θ 가 물체의 형상을
바꾸므로 후보마다 파지·충돌·경로를 다시 판정**해야 한다. 안전 인터록과
준정적 이동.  ✅ 작성됨

### F. Asset Compilation (0.1쪽)

밀도 → 질량·CoM·관성 → URDF 의 `<inertial>` 만 교체. 시뮬레이터로 되읽어
물리적 유효성 확인.  ✅ 작성됨

### E. Scaling to n Links, and Where It Stops (0.5쪽)

**이 절은 결과에 따라 갈리지 않는다.** 되면 되는 대로, 안 되면 왜 안 되는지를
쓴다. 그리고 **후자가 내용이 더 두껍다** — 이런 종류의 식별이 언제 무너지는지를
규정한 선행연구가 없기 때문이다.

#### E-1. 설정 (0.1쪽)

커스텀 물체의 치수 규칙을 그대로 이어붙인 `p = 2..8` 합성 사슬.
**힌지 유지토크는 시뮬레이션에서 개입하지 않으므로 제작 가능성과 무관하게
돌릴 수 있다.** `p=2,3` 이 실물과 미지수·rank·라운드 수까지 일치하므로
확장이 신뢰된다.

#### E-2. 어디까지 되는가 (0.1쪽)

**Fig. 3** — 목표 도달 라운드 수 vs `p`, 정리 3의 하한을 점선으로 겹침.
수렴한 구간과 못 한 구간을 그대로 보인다.

#### E-3. 왜 거기서 멈추는가 (0.3쪽) ★ 이 절의 본체

진단을 네 단계로 제시한다. 각 단계가 하나의 후보를 배제한다.

```
   ① 정보가 부족한가?            아니다
      부위별 SNR: p=8 의 말단조차 2.3 (밀도 1% 변화가 잡음의 2.3배)
      모든 부위가 개별적으로는 잡음 위에 있다

   ② 정보가 안 쌓이는가?          아니다
      반폭이 1/sqrt(R) 로 정상 감소 (측정 기울기 -0.46 ~ -0.97)
      벽이 아니라 속도다

   ③ 그럼 무엇이 다른가?          상수 C 가 커진다
      반폭 = C / sqrt(R) 에서 C 가 링크마다 약 2배씩
      p=3: 0.89   p=5: 13.7   p=8: 50.6
      필요 라운드는 C^2 이므로 링크마다 약 4배

   ④ C 는 왜 커지는가?           사슬이 되말리기 때문
      부위별 손목까지 거리 (p=8)
        75 -> 198 -> 258 -> 253 -> 190 -> 110 -> 109 -> 186 mm
                            └──┘         └──┘
                          5mm 차이     1mm 차이
      게다가 부위 6 은 관절을 전부 접어도 0.3mm 밖에 안 움직인다
```

그리고 **안 잡히는 것이 개별 부위가 아니라 이웃 부위의 차이**임을 보인다.

```
   가장 안 잡히는 방향 (부위 성분)
      p=5   [-0.00  0.00 -0.24  0.96 -1.00]
      p=8   [-0.00  0.04 -0.11  0.21 -0.51  1.00 -0.95  0.34]
```

말단 쪽 이웃이 반대 부호로 짝을 이룬다 — 정리 2의 영공간 바로 옆이다.
**즉 한계는 알고리즘이 아니라 물체의 기하가 정한다.**

> **Remark 로 넣을 것**: 정리 3의 하한은 "덧셈"으로 늘지만(미지수가 링크마다
> 2개씩) 실제 필요 라운드는 "곱셈"으로 는다(조건수가 링크마다 2배씩).
> 개수를 세는 것과 품질을 재는 것의 차이다.

#### E-4. 실용 한계와 물리 한계가 겹친다 (0.1쪽)

`p >= 4` 는 **마찰 힌지로 만들 수 없다.** 각 관절이 하류 전체를 버텨야 해서
필요 토크가 급격히 커진다.

```
   p=3  0.496 N·m  ->  하류 밀도 564 kg/m^3   제작 가능
   p=4  1.157      ->  242                   불가 (3D 프린트 하한 250)
   p=8  5.305      ->   53                   불가
```

휴대용 관절체(노트북·램프·폴더블폰)의 부위 수가 적은 것도 같은 이유다.
**방법의 실용 한계와 대상 물체군의 물리적 한계가 같은 자리에 있다.**

### F. Ablation Study (0.35쪽)

각 설계 선택이 값을 하는지. 기존 `study_*.py` 여덟 개에서 뽑는다.

| 무엇을 뺐을 때 | 결과 |
| --- | --- |
| TLS → WLS | 편향이 라운드로 안 사라짐 (8회 1.41% vs 1회 1.58%) |

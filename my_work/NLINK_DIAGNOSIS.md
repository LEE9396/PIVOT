## 2. 진짜 원인 (A) — 정보와 오염이 같은 관을 지난다

> ⚠ **8/27 정정.** 이전 판의 `130만 ~ 2535만 배` / `10^6 배` 는 근거가 없었다.
> 아래는 `rowsplit3.py` 로 실측한 값이다.

18행 중 12행은 `R_eff/R_sensor` 가 **정확히 1.00** 이다.

```
   힘 9행     F 에 theta 가 없다 -> 각도 민감도 0.  단 부위 구별 정보도 0
   토크 3행   tau 의 ghat 방향 성분. 외적이라 항상 0 -> 죽은 줄
   토크 6행   부위를 구별하는 유일한 통로            <- 아래는 이 6행만
```

```
   R_eff / R_sensor  (분산, 각도오차 5%)

    p        중앙        최대       크기 배율(중앙)
    2        10.9        17.3          3.3
    3        21.9       593.4          4.7
    4      41,690     134,600        204.2
    5      82,950   1,076,000        288.0
    6      25,910      40,550        161.0
    8     102,200     204,900        319.6
```

정리 1이 **"힘 채널은 저울과 중복이므로 부위별 정보는 전부 토크에서 온다"** 고
말한다. 그런데 그 토크가 각도 오차에 지배되는 자리다.
**유일한 정보 통로가 유일한 오염 통로와 같다.**

**p=3 -> p=4 에서 판이 뒤집힌다** (22배 -> 4만 배).

그래서 안 잡히는 것은 개별 부위가 아니라 **이웃한 두 부위의 차이**다.

```
   가장 안 잡히는 방향 (부위 성분)
      p=5   [-0.00  0.00 -0.24  0.96 -1.00]
      p=8   [-0.00  0.04 -0.11  0.21 -0.51  1.00 -0.95  0.34]
```

말단 쪽 이웃 부위가 반대 부호로 짝을 이룬다 — 정리 2의 영공간(질량·1차모멘트
보존 재배치) 바로 옆이다. 관절을 접으면 갈라지지만, 말단 부위끼리는 모멘트팔이
비슷해서 **조금밖에 안 갈라진다.**

### 그런데 이건 벽이 아니라 속도다

라운드를 늘리면 반폭이 `1/√R` 로 정상 감소한다 (측정한 기울기 −0.46 ~ −0.97).

```
   p    R=2      R=5     R=10    R=20    R=40    목표 1% 필요 라운드
   3    0.47     0.38    0.27    0.20    0.14         (이미 도달)
   4   57.00     1.58    1.49    1.11    1.02         약  44
   5  200.05     7.59    4.35    3.28    2.16         약 148
   6  334.65    25.29    8.37    5.78    4.30         약 421
```

**원리상 가능하다.** 다만 실물에서 한 라운드가 1~2분이므로 p=5 는 2~5시간,
p=6 은 7~14시간이다.

## 3. 진짜 원인 (B) — 추정기와 탐색이 먼저 무너진다

정보는 위처럼 쌓이는데, **추정이 그걸 못 따라간다.**

```
20라운드 시점 부위 질량오차 % (평균/최악, 수렴 성공)
                            p=4              p=5              p=6
   기준 (starts=6, TLS)   3.34/12.79      0.83/1.76      12.34/46.47   (0/4)
   시작점 24개 (TLS)      4.95/10.56     25.64/100.91    75.07/222.12  (0/4)
   WLS (starts=6)        14.56/18.70     34.59/67.01     38.83/95.22   (0/4)
```

읽을 것 두 가지.

**(B1) TLS 는 제 몫을 하고 있다.** WLS 로 바꾸면 4~40배 나빠진다.
오차변수 보정이 실제로 작동한다는 뜻이므로 이 선택은 유지한다.

**(B2) 최적화를 더 잘하면 오히려 나빠진다.** 시작점을 6→24 로 늘리면
p=5 가 0.83 % 에서 25.64 % 로 **30배 나빠진다.** 이건 "탐색이 부족하다" 의
반대다.

> **가설**: 정리 3은 쌓인 `C(θ_r)` 들의 **행공간이 상보적**이어야 한다고
> 말한다. 그런데 한 걸음 D-최적은 매 라운드 '지금 가장 좋은 한 점' 을 고르고,
> 목적함수는 라운드 사이에 조금밖에 안 변한다. **최적화를 잘할수록 매번 거의
> 같은 자세를 고르게 된다.** 시작점이 적으면 국소해가 매번 달라져 우연히
> 다양해진다 — 나쁜 최적화가 정칙화 노릇을 하고 있다.
>
> 사실이라면 고칠 것은 "탐색을 더 잘하는 것" 이 아니라
> **"다양성을 명시적으로 강제하는 것"** 이다. ([diag_diversity.py](diag_diversity.py))

또 하나. **TLS 미지수가 `P + R×J` 로 라운드에 비례해 늘어난다.**
p=5 에 R=150 이면 9 + 600 = 609 개다. 라운드를 늘리는 것 자체가 추정을
어렵게 만든다.

## 3-b. 더 좁혀진 원인 — 기준(criterion)이 엉뚱한 것을 최대화한다 ★

(B2) "최적화를 잘할수록 나빠진다" 의 정체를 찾았다. 무작위 자세 200개에서
'벌어짐', '토크 신호', '각도잡음 배율', 'D 효용' 을 같이 재보면 이렇다.

```
p=8 — 무작위 자세 200개 중
                  벌어짐    토크신호   각도잡음배율   신호/잡음    D효용
   D효용 1위        56mm   1.73e-03      2449      7.06e-07    82.97  <- D 가 고르는 것
   벌어짐 1위      150mm   3.71e-03       476      7.80e-06    82.08
   신호/잡음 1위   146mm   3.53e-03       277      1.28e-05    81.56  <- 18배 좋은데
                                                                        D 는 더 낮게 봄
   상관: D효용 vs 벌어짐 +0.64   신호 vs 잡음 -0.58
```

**신호와 잡음이 같이 커진다는 가설은 틀렸다** (상관 −0.58, 오히려 반대).
잘 벌어진 자세는 신호가 2배 크고 잡음이 5배 작다 — 명백히 더 좋다.
그런데 **D-최적이 그것을 더 낮게 평가한다.**

### 왜 그런가

**(1) D 는 '가장 안 보이는 방향' 이 아니라 '정보 부피' 를 본다.**
`log det` 은 모든 방향의 이득을 곱한 값이라, 이미 잘 보이는 방향 셋을 크게
개선하는 자세가 안 보이는 방향 하나를 살리는 자세를 이길 수 있다.

```
   방향별 이득 (1000, 1000, 1000, 0)  -> log det = 20.7   <- D 가 선호
   방향별 이득 ( 100,  100,  100, 100) -> log det = 18.4
```

한 방향을 아예 안 건드리는 자세가 이긴다. 게다가 정리 2에 의해 한 자세는
어차피 rank 4 까지만 주므로, D 는 "가장 쉬운 4개 방향" 쪽으로 기운다.
부위가 많아질수록 남겨지는 방향이 늘어난다.

**(2) 지형이 평평해서 순위가 무의미하다.**
200개 자세에 걸쳐 D 효용은 73~83 (13 % 범위) 인데, 같은 자세들의 신호/잡음은
18배 차이가 난다. 잡음 섞인 수치 최적화가 이 안에서 매기는 순위는 사실상
동전 던지기다. **시작점을 24개로 늘리면 나빠지던 이유가 이것이다** — 평평한
지형에서 열심히 최적화하면 미세한 차이를 좇아 매번 비슷한 자세로 수렴한다.

### ⚠ 위 해석은 틀렸다 — 직접 재보니 D 가 압도적으로 낫다

기준을 바꿔 폐루프를 20라운드씩 돌려 본 결과다.

```
   20라운드 후 최악 방향 반폭 [%]
    p      D (지금)      SPREAD      SIGMIN
    4        1.19        87.16      189.97
    5        3.51       194.09        6.24
    6        6.28       276.85       90.24
    8       10.74       454.68       61.61
```

**D 가 대안들보다 8~40배 낫다.** "기준이 엉뚱한 것을 최대화한다" 는 위 해석은
틀렸다.

**어디서 틀렸나.** 200개 자세를 비교할 때 `SIGMA0` 를 고정해서 재는 바람에
**1라운드 상황만** 본 것이다. 실제 폐루프에서 D 는 매 라운드 현재 사후분포
`Sigma` 를 보고 **적응한다** — 지금 안 보이는 방향을 골라 노린다.

SPREAD 는 `Sigma` 를 안 본다. 그래서 매 라운드 똑같은 '가장 벌어진 자세' 를
고르고, 같은 것만 반복해 재게 된다. **정리 3이 요구하는 행공간 상보성이 전혀
안 생긴다.** 즉 이 실험은 오히려 이론을 뒷받침한다 — 기준은 사후분포에
적응해야 하고, D 가 바로 그것을 한다.

### 그러면 남는 설명은 '다양성' 하나다

증거가 일관된다.

```
   D + 시작점 6개    (국소해가 매번 달라짐 -> 자세 다양)   p=5    0.83 %
   D + 시작점 24개   (매번 전역최적 -> 자세 비슷)         p=5   25.64 %
   SPREAD           (완전히 고정된 자세 반복)             p=5  194.09 %
```

**자세가 반복될수록 나빠진다.** 한 걸음 D-최적은 목적함수가 라운드 사이에
조금밖에 안 변하므로, 최적화를 잘할수록 같은 자세로 수렴한다. 시작점이 적으면
그게 우연히 깨진다.

**그러므로 고칠 것은 기준이 아니라 D 에 다양성을 더하는 것이다.**
([diag_diverse_fix.py](diag_diverse_fix.py) 로 확인 중)

## 4-b. 이론이 먼저 배제하는 트릭들

"n-link 도 되게 하는 방법" 을 찾을 때, 아래 넷은 **가장 먼저 떠오르지만
정리에서 이미 배제된다.** 실험할 필요가 없다.

| 아이디어 | 왜 안 되나 |
| --- | --- |
| 파지점을 바꾼다 | `tau' = tau − d x f`. d 와 f 를 이미 아니까 새 정보가 아니라 재조합이다 |
| 더 여러 방향으로 기울인다 | 정리 1 — 직교 3방향이면 천장. 4·6 방향 모두 rank 4 |
| 물체를 돌려 잡는다 | 삼면체 불변성과 같은 이유로 정보량 불변 |
| 더 정밀한 F/T 센서 | 토크 잡음은 각도 오차가 지배(p>=4 에서 4만배 이상). **잡음 0 짜리 센서를 써도 반폭 개선은 p>=4 에서 0.001 %** |

**이것이 정리를 세운 실용적 값어치다** — 안 되는 것을 실험하지 않고 걸러낸다.

정보를 늘리려면 `M = a·vv^T + b·C(θ)^T C(θ)` 에서 **C 를 바꾸는 수밖에 없고**,
방법은 셋뿐이다.

```
   ① 미지수를 줄인다        같은 힌지는 하나의 밀도로 (2p−1 -> p+1)
   ② 사전지식으로 막는다     밀도의 물리적 상하한
   ③ C 자체를 바꾼다        물체가 되말리지 않게 / 부분만 재기
```

### ④ 물리적 트릭 — 물체 일부를 받쳐서 부분만 재기

정리 2의 rank 4 천장을 **우회하는 유일한 방법**이다.

```
   지금  : 전체를 들고 잰다        -> 전체의 질량·무게중심 (4 개)
   제안  : 책상에 놓고 한 링크만 들어올린다
           -> 들린 부분만의 질량·무게중심
           -> 들어올리는 링크를 바꿔가며 반복
           -> 부분집합마다 4 개씩,  차이를 빼면 각 부위가 직접 나온다
```

생체역학의 반응판이 쓰는 방법이다. 다만 **접촉력이 미지수로 들어온다** —
접촉점을 하나로 만들거나(모서리에 걸치기) 그 아래 저울을 두어야 한다.
실물 실험이 상당히 복잡해진다.

## 5. 검토해 주실 것

**질문 1. 어디까지를 논문 범위로 둘 것인가.**

```
   (가) p<=3 만        지금 확실히 되는 구간. 실물 4개가 전부 여기 있다.
                       n-link 는 "한계의 위치와 원인" 으로 서술.
   (나) p<=5 까지      S1+S2+S4 를 적용해 시뮬레이션에서 수렴시킨다.
                       "n-link 에서 검증했다" 를 쓸 수 있다. 며칠 걸린다.
   (다) S5/S6 까지     알고리즘 개선이 기여에 추가된다. 위험하지만 논문이 세진다.
```

**질문 2. S2(힌지 묶기)를 실물에도 적용할 것인가.**
2-link 와 3-link 는 **실제로 같은 힌지**(명가철물, 실측 41 g)를 쓴다. 그러면
지금처럼 힌지마다 따로 두는 것이 아니라 **하나의 밀도로 묶는 것이 물리적으로
더 옳다.** 미지수가 3-link 에서 5 → 4 로 줄고, 정리 3의 하한도 2 → 1 로
바뀐다. **다만 그러면 "3-link 하한 2 = 관측 2" 라는 지금의 검증 사례가
사라진다.** 어느 쪽이 나은지 판단이 필요하다.

**질문 3. S4(라운드 확대)를 실물에서 감당할 것인가.**
p<=3 은 1~2 라운드라 무관하다. 시뮬레이션 스윕에만 적용하면 된다.

## 1. 이 논문의 한 줄 논지

> 관절체의 부위별 밀도를 **추측이 아니라 측정으로** 알아내 sim-ready asset 을
> 만든다. 그러려면 **물체의 형상을 바꿔야 한다**는 것을 보이고, 몇 번 바꿔야
> 하는지를 계산해 실물과 시뮬레이션 양쪽으로 확인한다.

**주 목적은 asset 생성이다.** 이론은 그것을 떠받치는 근거이지 논문의 산출물이
아니다. 이 우선순위가 절 배치와 표현 수위를 전부 결정한다.

### 왜 이 방향인가

부피 오차가 한 자릿수로 들어오면서 판단이 바뀌었다.

```
   부피 오차 5 %  ->  3-link 질량 오차 1.64 % ,  desk lamp 0.79 %
   VLM baseline   ->  부위 질량 오차 수십 ~ 수백 %
```

**주장이 절대적("정확한 asset")이 아니라 상대적("추측보다 측정이 낫다")이므로
재구성 품질이 주장을 흔들지 못한다.** 그래서 이론 쪽으로 방향을 틀 필요가 없다.

## 2. Contribution (확정, 영문 그대로 사용)

```latex
\begin{itemize}
    \item Identifiability analysis in the density parameterization, where the
    classical static limit---mass and center of mass only---becomes a bound on
    the number of parts, and yields a lower bound on the number of
    configurations that our objects meet with equality.
    \item Active estimation strategy that selects the most informative joint
    configurations to collapse the null space of the density estimate,
    minimizing overall estimation time.
    \item Pipeline with minimal user intervention that turns real-world
    observations and interactions into sim-ready articulated assets faithful in
    both appearance and dynamics, without damaging joints.
    \item Real-world experiments on four articulated objects, two with
    controllable ground-truth densities, where the predicted number of
    configurations is met with equality, and a simulation sweep to eight links.
\end{itemize}
```

2·3 번은 원래 저자가 쓴 문장 그대로다. 1 번이 새로 들어갔고 4 번은 개수만 고쳤다.
**순서가 중요하다** — 분석 → 전략 → 파이프라인 → 검증.

## 3. 이론 — 전부

### 3-1. 측정 모형

부위 `P` 개(부위 + 힌지), 부피 `V_i`, 미지 밀도 `rho_i`. 손목 센서 프레임 `S`,
관절형상 `theta`, 부위 도심 `c_i(theta)`, 중력 단위벡터 `g_hat`.

```
   v    = (V_1..V_P)^T                      부피 벡터
   C(θ) = [V_1 c_1(θ) ... V_P c_P(θ)]       부피가중 도심행렬 (3 x P)

   y = A(θ, ĝ) ρ + ε ,      A = g [  ĝ v^T      ]
                                  [ -[ĝ]_x C(θ) ]
```

센서 잡음 `R = blkdiag(σ_f² I₃, σ_τ² I₃)` — 블록 등방. **이 가정을 명시할 것.**

### 3-2. Lemma 1 (닫힌 형태) — *"we recall"* 로 쓸 것

임의의 단위벡터 집합 `{ĝ_k}` (K 개) 에 대해

```
   M(θ) = g² [ (K/σ_f²) v v^T + (1/σ_τ²) C^T ( K I₃ − Σ_k ĝ_k ĝ_k^T ) C ]
```

증명: `ĝ^T ĝ = 1`, `[ĝ]_x^T [ĝ]_x = I − ĝĝ^T`. 두 줄.

**Cor. 1 (삼면체 불변성)**: 직교정규 삼면체면 `Σ ĝĝ^T = I` 이므로

```
   M(θ) = g² [ (3/σ_f²) v v^T + (2/σ_τ²) C(θ)^T C(θ) ]
```

삼면체를 통째로 돌려도 불변. 따라 나오는 것 셋:
- 설계공간이 `Θ × SO(3)` → `Θ`
- `M` 에 `ρ` 가 없다 → **각도가 정확하면 개루프로 충분. 폐루프의 유일한 이유는 각도 오차**
- 힘 항이 `v v^T` 하나뿐 → **힘 채널은 저울과 중복. 정보는 전부 토크에서**

### 3-3. Prop 1 (rank 천장) — *"we recall"* 로 쓸 것

```
   rank M(θ) ≤ 1 + rank C(θ) ≤ 1 + min(3, P) = 4
```

방향 개수·배치와 무관. 증명: `K I − Σ ĝĝ^T ⪰ 0`, rank 준가법성.

**Cor. 2 (강체 한계)** ★ 가장 중요한 문장
> 형상을 고정하면 중력 방향을 몇 개 쓰든 몇 번 반복하든 rank 4 이하다.
> 즉 **강체 조립품은 부위 5개 이상이면 사전지식 없이 식별 불가능하다.**

이것이 Sum of Its Parts 가 균질 부위 가정을, Scalable Real2Sim 이 단일 페이로드
모형을 쓸 수밖에 없었던 이유를 설명한다. **남의 연구를 설명해 주는 결과다.**

### 3-4. Prop 2 (영공간)

```
   null M(θ) = { u : Σ u_i V_i = 0  이고  Σ u_i V_i c_i(θ) = 0 }
```

**총질량과 손목 기준 1차 모멘트를 동시에 보존하는 재배치는 보이지 않는다.**
증명: `M = a vv^T + b C^T C`, `u^T M u = 0`.

### 3-5. Prop 3 (라운드 하한) — **새로 주장하는 것**

```
   rank M_R ≤ 1 + min(3R, P)     ⇒     R ≥ ⌈(P−1)/3⌉
   링크 p 개 + 관절마다 힌지면 P = 2p−1 ⇒  R ≥ ⌈(2p−2)/3⌉
```

**형상만으로 계산된다** (`M` 에 ρ 가 없으므로). 그리고 실물과 등호로 맞는다.

**Remark (필요조건 ≠ 충분조건)** — 반드시 넣을 것
> 하한은 **덧셈**으로 는다(링크마다 미지수 2개). 실제 필요 라운드는 **곱셈**으로
> 는다(조건수가 링크마다 약 2배 → 라운드 4배). 개수를 세는 것과 품질을 재는
> 것의 차이다.

### 3-6. 표현 수위 (중요)

| | 어떻게 쓸 것인가 |
| --- | --- |
| Lemma 1, Prop 1 | **"we recall, in the density parameterization"**. 정적 측정이 질량·무게중심만 준다는 것은 교과서 사실(Atkeson·An·Hollerbach 1986) |
| Cor. 2, Prop 3 | **"we show"**. 재매개화가 만드는 귀결과 라운드 하한이 새로운 것 |
| TLS/EIV | **인용하고 넘어갈 것**(IDIM-TLS 계열). 우리 것은 도구가 아니라 *"오차원이 설계변수 자신"* 이라는 구조 |
| D-최적 | Gautier·Khalil 1992, Swevers 1997 인용 필수. 안 하면 desk-reject 급 구멍 |

   메울 수밖에 없다" — **세 편의 선행연구가 왜 각각 다른 사전지식을 썼는지를

**A 의 ScrewSplat·ArtSplat 를 한 절로 축약** — 실제로 쓰는 것은 RORA 하나다.

## 6. 아직 본문에 안 들어간 것 — **반드시 추가**

### Method D 에 넣을 문단 (새 발견)

> 미지수로 함께 푼 것은 잔차를 잴 때도 반영해야 한다. TLS 가 맞춘 모형은
> `y ≈ A(θ+δ)ρ` 인데 잔차를 `y − A(θ)ρ` 로 재면 TLS 가 찾아낸 각도 보정량이
> 통째로 잔차로 잡힌다. 그러면 팽창이 **79배**까지 뛰고, 추정이 이미 목표를
> 넘었는데도 정지 조건이 만족되지 않는다.
>
> ```
>            팽창 배율        보고 반폭        실제 오차
>   p=4    79.3 -> 1.05    89.17% -> 1.18%     0.28%
>   p=5    94.3 -> 1.13   156.10% -> 1.87%     0.89%
> ```
>
> 오차변수 추정기와 잔차 기반 정지 조건을 함께 쓸 때 구조적으로 빠지는
> 함정이다. 코드는 `design_core.residual_scale` 로 고쳤다.

### 같은 성격의 두 번째 발견 — TLS 반복 상한

`tls_map` 의 `max_nfev` 가 400 으로 고정돼 있었다. 미지수는 `P + R*J` 로
라운드에 비례해 늘고 수치 미분이라 야코비안 한 번에 미지수 개수만큼 평가가
드는데, 상한은 고정이었다.

```
   p    미지수   상한 400 : nfev  오차%   |  상한 해제 : nfev  오차%
   4      52         20      0.25   |         20      0.25
   6      86        400     13.36   |        547      1.11    <- 12배
   8     120        166      4.60   |        166      4.60    <- 상한 문제 아님
```

**p=6 은 547 회면 수렴하는데 400 에서 잘리고 있었다.** `max_nfev=None` 로
바꾸면 scipy 가 `100*n` 을 쓴다 — 문제 크기에 맞춰 준다.

> **두 발견의 공통점**: 부위가 2~3 개일 때는 문제가 안 드러났다가, 부위가
> 늘면서 조용히 부족해진 설정들이다. **"n-link 가 안 된다" 의 상당 부분이
> 정보 한계가 아니라 이런 설정 문제였다.**

## 8. 함정 — 같은 실수를 반복하지 않도록

이 연구를 검토하면서 **세 번 틀린 결론을 내고 정정했다.** 새 대화에서 같은
길을 다시 가지 않도록 적어 둔다.

| 틀린 결론 | 실제 | 어떻게 갈렸나 |
| --- | --- | --- |
| "D-최적이 엉뚱한 것을 최대화한다" | **D 가 대안보다 8~40배 낫다** | 자세 200개를 `SIGMA0` 고정으로 비교해서 1라운드 상황만 봤다. 폐루프에서 D 는 사후분포에 **적응**한다 |
| "자세가 반복돼서 나쁘다" | 다양성을 더해도 안 좋아짐 | seed 4개 비교의 잡음을 과잉 해석했다 |
| "p≥5 는 어떤 예산에서도 안 된다" | 예산이 짧았고, **정지 조건 버그**가 컸다 | 12~30라운드로 판정했다. 실제 필요는 수십~수백 |
| "1만 6천 라운드 필요" | 수백 라운드 | R=8 의 나쁜 값에서 외삽했다 |

**교훈**: 폐루프 알고리즘을 단일 라운드 지표로 판단하지 말 것. seed 를 충분히
쓸 것. 그리고 "안 된다" 는 결론 전에 **추정 오차와 보고 반폭을 따로 볼 것** —
둘이 100배 차이 날 수 있다.

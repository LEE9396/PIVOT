## 1. 이 논문의 한 줄 논지

> 관절체의 부위별 밀도를 **추측이 아니라 측정으로** 알아내 sim-ready asset 을
> 만든다. 그러려면 **물체의 형상을 바꿔야 한다**는 것을 보이고, 몇 번 바꿔야
> 하는지를 계산해 실물과 시뮬레이션 양쪽으로 확인한다.

**주 목적은 asset 생성이다.** 이론은 그것을 떠받치는 근거이지 논문의 산출물이
아니다. 이 우선순위가 절 배치와 표현 수위를 전부 결정한다.

### 왜 이 방향인가

부피 오차가 한 자릿수로 들어오면서 판단이 바뀌었다.

```
   부피 오차 5 %  ->  3-link 질량 오차 1.64 % ,  desk lamp 0.79 %
   VLM baseline   ->  부위 질량 오차 수십 ~ 수백 %
```

**주장이 절대적("정확한 asset")이 아니라 상대적("추측보다 측정이 낫다")이므로
재구성 품질이 주장을 흔들지 못한다.** 그래서 이론 쪽으로 방향을 틀 필요가 없다.

## 2. Contribution (8/27 개정, 영문 그대로 사용)

```latex
\begin{itemize}
    \item \textbf{Identifiability analysis in the density parameterization.}
    The classical static limit---that gravity-only wrenches resolve nothing beyond
    total mass and center of mass---becomes, under this parameterization, a bound on
    how many parts a single configuration can separate. From it follows a lower bound
    on the number of configurations that is computable from the reconstructed geometry
    alone, before any wrench is measured, and that our objects meet with equality.

    \item \textbf{Active estimation under manipulation constraints.}
    We select the joint configuration that collapses the null space a fixed
    configuration leaves, reaching a target uncertainty in fewer configurations than
    static or geometry-driven alternatives. Because the design variable is the
    object's own shape rather than the robot's trajectory, each candidate must be
    re-verified for grasp, reachability and collision \emph{at that configuration}---a
    coupling absent from classical excitation design.

    \item \textbf{Pipeline with minimal user intervention} that turns real-world
    observations and interactions into sim-ready articulated assets faithful in both
    appearance and dynamics, without damaging the joints.

    \item \textbf{Real-world experiments on four articulated objects, two with
    controllable ground-truth densities, where the predicted number of configurations
    is met with equality, together with a simulation sweep over randomly proportioned
    chains of up to six links} that isolates joint-angle measurement precision---rather
    than force/torque resolution or configuration selection---as what governs how
    closely the bound can be approached, and reports the precision each part count
    requires.
\end{itemize}
```

**순서가 중요하다** — 분석 → 전략 → 파이프라인 → 검증.

## 3. Theoretical Contribution — 증명한 것

### 3-1. 측정 모형

부위 `P` 개(부위 + 힌지), 부피 `V_i`, 미지 밀도 `rho_i`. 손목 센서 프레임 `S`,
관절형상 `theta`, 부위 도심 `c_i(theta)`, 중력 단위벡터 `g_hat`.

```
   v    = (V_1..V_P)^T                      부피 벡터
   C(θ) = [V_1 c_1(θ) ... V_P c_P(θ)]       부피가중 도심행렬 (3 x P)

   y = A(θ, ĝ) ρ + ε ,      A = g [  ĝ v^T      ]
                                  [ -[ĝ]_x C(θ) ]
```

센서 잡음 `R = blkdiag(σ_f² I₃, σ_τ² I₃)` — 블록 등방. **이 가정을 명시할 것.**

### 3-2. Lemma 1 (닫힌 형태) — *"we recall"* 로 쓸 것

임의의 단위벡터 집합 `{ĝ_k}` (K 개) 에 대해

```
   M(θ) = g² [ (K/σ_f²) v v^T + (1/σ_τ²) C^T ( K I₃ − Σ_k ĝ_k ĝ_k^T ) C ]
```

증명: `ĝ^T ĝ = 1`, `[ĝ]_x^T [ĝ]_x = I − ĝĝ^T`. 두 줄.

**Cor. 1 (삼면체 불변성)**: 직교정규 삼면체면 `Σ ĝĝ^T = I` 이므로

```
   M(θ) = g² [ (3/σ_f²) v v^T + (2/σ_τ²) C(θ)^T C(θ) ]
```

삼면체를 통째로 돌려도 불변. 따라 나오는 것 셋:
- 설계공간이 `Θ × SO(3)` → `Θ`
- `M` 에 `ρ` 가 없다 → **각도가 정확하면 개루프로 충분. 폐루프의 유일한 이유는 각도 오차**
- 힘 항이 `v v^T` 하나뿐 → **힘 채널은 저울과 중복. 정보는 전부 토크에서**

### 3-3. Prop 1 (rank 천장) — *"we recall"* 로 쓸 것

```
   rank M(θ) ≤ 1 + rank C(θ) ≤ 1 + min(3, P) = 4
```

방향 개수·배치와 무관. 증명: `K I − Σ ĝĝ^T ⪰ 0`, rank 준가법성.

**Cor. 2 (강체 한계)** ★ 가장 중요한 문장
> 형상을 고정하면 중력 방향을 몇 개 쓰든 몇 번 반복하든 rank 4 이하다.
> 즉 **강체 조립품은 부위 5개 이상이면 사전지식 없이 식별 불가능하다.**

이것이 Sum of Its Parts 가 균질 부위 가정을, Scalable Real2Sim 이 단일 페이로드
모형을 쓸 수밖에 없었던 이유를 설명한다. **남의 연구를 설명해 주는 결과다.**

### 3-4. Prop 2 (영공간)

```
   null M(θ) = { u : Σ u_i V_i = 0  이고  Σ u_i V_i c_i(θ) = 0 }
```

**총질량과 손목 기준 1차 모멘트를 동시에 보존하는 재배치는 보이지 않는다.**
증명: `M = a vv^T + b C^T C`, `u^T M u = 0`.

### 3-5. Prop 3 (라운드 하한) — **새로 주장하는 것**

```
   rank M_R ≤ 1 + min(3R, P)     ⇒     R ≥ ⌈(P−1)/3⌉
   링크 p 개 + 관절마다 힌지면 P = 2p−1 ⇒  R ≥ ⌈(2p−2)/3⌉
```

**형상만으로 계산된다** (`M` 에 ρ 가 없으므로). 그리고 실물과 등호로 맞는다.

**Remark (필요조건 ≠ 충분조건)** — 반드시 넣을 것
> 하한은 **덧셈**으로 는다(링크마다 미지수 2개). 실제 필요 라운드는 **곱셈**으로
> 는다(조건수가 링크마다 약 2배 → 라운드 4배). 개수를 세는 것과 품질을 재는
> 것의 차이다.

### 3-5b. Remark (채널 분리) — **정리로 내세우지 말 것**

`F(θ, ĝ) = −g (v^T rho) ĝ` 에서

```
   (i)   F 에 theta 가 없다      -> dF/dtheta = 0 (항등적)
                                 -> 각도 오차 야코비안 J 의 힘 블록 = 0
                                 -> 각도 오차는 토크 행만 오염시킨다

   (ii)  rho -> F 의 행렬 = −g ĝ v^T,  rank 1,  행공간 = span{v}
                                 -> 힘 행은 v^T rho (총질량) 하나만 결정
                                 -> 그 값은 저울로 얻는다

   =>  부위를 구별하는 부분공간 = 각도 오차가 오염하는 부분공간
   =>  sigma_f 를 줄여도 저울이 이미 고정한 방향 외에는 못 줄인다
```

**격**: *"물체를 접어도 총 무게는 그대로"* 는 초등 물리다. 번호 붙은
Proposition 으로 만들면 순진해 보인다. **Remark 한 문단**으로 두고, IV-D 에서
*"센서는 지렛대가 아니다"* 를 측정이 아니라 구조로 말하게 하는 데 쓴다.

### 3-6. 표현 수위 (중요)

**② 하한은 각도와 무관하다** — rank 조건이라 `R_eff` 가 양의 정부호인 한
`rank(A^T R_eff^-1 A) = rank(A)` 다. 그림 A 에서 점선 바닥이 네 칸 모두 평평한
것이 그것이고, **실선이 그 바닥으로 내려오는 만큼이 조건수**다. `Remark
(necessary, not sufficient)` 의 그림 증거로 이만한 것이 없다.

**③ 반폭이 라운드보다 민감하다.** p=4 는 라운드가 1~10 % 내내 3으로 같은데
반폭은 0.86 → 1.21 % 로 갈린다. **라운드 수만 보면 각도의 영향을 놓친다** —
그래서 그림 B 가 따로 필요하다.

**그림 B 는 설계 차트다.** 곡선이 목표선을 가로지르는 지점이 그 물체에 필요한
각도 정밀도다.

```
   p <= 4    10 % 로도 통과
   p = 5     5 % 근처
   p = 6     2 % 근처
```

> ⚠ **'—' 의 뜻**: *14라운드 예산 안에* 못 닿았다는 뜻이지 절대 불가가 아니다.
> seed 8·30라운드 판(7-d 최종 수치)에서는 p=6·rel=5 % 가 15~24라운드로 4/8

> 관절각이 작을 때 rel=1 % 는 하한에 걸린다. **x축 왼쪽 끝은 "1 %" 가 아니라
> "1 % 또는 0.5도 중 큰 쪽"** 이다. 본문에 한 줄 달 것.

**분량**: A 1문단 + B 2문단 + C 2문단 = 5문단. 0.7쪽에 빠듯하다. 넘치면
**A 의 ScrewSplat·ArtSplat 를 한 절로 축약** — 실제로 쓰는 것은 RORA 하나다.

**시뮬레이션이 실물보다 먼저인 이유**: GT 가 정확한 곳에서 알고리즘을 먼저
검증해야, 리뷰어가 실물 오차가 알고리즘 탓인지 재구성 탓인지 가릴 수 있다.

**baseline 이 두 종류로 갈린다** — 시뮬에서는 vision baseline 을 못 돌린다

             <- Cor.2 가 예측한 실패를 직접 보이는 자리
   실물 (E)  PUGS / SiPhy / PhysX-Omni
```

#### C (Volume Estimation) 에서 무엇을 쓰나 — **baseline 비교 포함**

```
   비교 대상
     우리 (mesh refinement)        실제로 파이프라인이 쓰는 부피
     Bounding box / Convex hull    형상 정보를 얼마나 쓰는지 보이는 하한
     PUGS 의 Gaussian 적분         밀도 baseline 이 실제로 쓰는 부피
     PhysX-Omni 의 생성 형상       〃

   GT 는 B 절의 **수중 배수법 실측값** -> 절대 비교가 가능하다
   커스텀 물체는 CAD 적분값도 있으므로 배수법 자체의 검증도 된다
```

**왜 baseline 비교가 필요한가** — 이것이 재구성 연구를 하려는 것이 아니다.
논문의 주 결과가 *"부위별 질량 오차로 baseline 을 이긴다"* 인데, 리뷰어가
**"그 우위가 추정이 좋아서인가, 형상이 좋아서인가?"** 를 묻는다. PUGS 는
Gaussian volume integration 으로, PhysX-Omni 는 생성 모델로 형상을 얻으므로
**각 방법이 서로 다른 형상을 쓴다.** 부피를 같이 재야 질량 비교의 타당성이
선다.

**같이 보고할 것**: 도심 오차, 그리고 이미 잰 민감도

```
   부피 10 % -> 질량 6 % ,   도심 1 mm -> 질량 2.4 %
```

이 둘을 짝지어 쓰면 *"우리 형상은 X % 틀리고 그것이 질량에 Y % 기여한다"* 가
되어, 뒤에 나오는 질량 표를 읽는 기준이 된다.

#### E (실물) 의 핵심 — **네 갈래 비교** ★

`GT / vision baseline / Ours(sim) / Ours(real)` 을 한 표에 놓는다. 각 열이
서로 다른 질문에 답한다.

```
   GT  vs  baseline      "추측이 얼마나 틀리나"           -> 주장의 근거
   GT  vs  Ours(real)    "우리가 얼마나 맞나"             -> 주 결과
   Ours(sim) vs (real)   "알고리즘 탓인가 현실 탓인가"     ★ 이 논문의 정직성
```

**Tab. II 형식**

```
   물체 | 부위 | GT | PUGS | SiPhy | PhysX-Omni | Ours(sim) | Ours(real)
```

**`Ours(sim)` 이 우리 방법의 상한**이다. 시뮬레이션은 완벽한 측정을 가정하므로
알고리즘이 낼 수 있는 최선이고, 실물이 거기서 벌어진 만큼이 **시뮬이 모형화
하지 않은 것 전부**다 — 타어링 오차, 파지 반복도, 실제 각도 추적 오차,
재구성 오차.

```
   sim 0.1 % -> real 0.5 %   파이프라인이 잘 구현됨. 현실 요인이 작다
   sim 0.1 % -> real 5.0 %   모형화 안 된 것이 있다 -> 어디인지 규정한다
```

**어느 쪽이든 논문이 된다.** 앞이면 *"실물에서도 된다"*, 뒤면 *"현실의 어느
요인이 지배적인지 규정했다"* 다.

#### 이 비교가 성립하려면 — 설계에서 지킬 것 둘

**① 시뮬과 실물이 같은 물체 모형을 써야 한다.**

```
   ✗  시뮬은 CAD, 실물은 스캔     -> 차이에 '모형 차이' 가 섞인다
   ✓  둘 다 같은 재구성 결과      -> 차이가 '측정 사슬' 만
```

커스텀 물체는 CAD 가 있어 시뮬에 그것을 쓰기 쉬운데, 그러면 sim-real 격차가
*"알고리즘 vs 현실"* 이 아니라 *"CAD vs 스캔"* 이 섞인다. **둘 다 스캔
모형으로 돌려야 통제된다.**

**② 시뮬의 각도 오차를 실측값으로 맞춰야 한다.**

지금 시뮬은 각도 오차 5 % 를 가정한다. 실물 세션에서 트래커의 **실제** 오차를
재서(고정 장면 반복 측정) 그 값으로 시뮬을 다시 돌리면, *"기대치"* 가 아니라
*"이 조건에서 나와야 할 값"* 이 된다. 그것과 실물을 비교해야 격차의 의미가
분명해진다.

#### 실물 세션 절차 — 물체마다 한 번에

```
   1. 저울로 총질량                              (사전분포)
   2. **트래커 오차 실측** (고정 장면 반복)       <- ② 를 위해. 새로 추가
   3. 밀도 추정 폐루프                           -> 주 결과
   4. 같은 물체 3~5 회 반복                      -> 반복성
   5. 라운드별 시각 로그                          -> 소요 시간 (자동)
   6. 관절 놓고 처지는 영상                       -> 시뮬레이터 재생 검증 (Fig.4)
   7. (램프) 분해 -> 저울 + 배수법                -> GT
   8. (노트북) 기지 추 50 g 부착 후 3 을 한 번 더  -> 부위 귀속 검증
   ─────────────────────────────────────────────
   9. 세션 후: **같은 모형·같은 각도오차로 시뮬 재실행**  <- Ours(sim) 열
```

**9번은 세션 뒤 컴퓨터에서만 하면 된다. 추가 장비 시간이 안 든다.**

#### D 안의 n-link 부분 — **결과에 독립적인 4단**

```
   D-1  설정        합성 사슬. p=2,3 이 실물과 미지수·rank·라운드까지 일치
   D-2  어디까지    Fig.3 — 라운드 vs p, 하한을 점선으로 겹침
   D-3  왜 멈추나 ★ SNR 충분(p=8 말단 2.3) -> 정보 부족이 아님
                    -> 부위를 구별하는 정보는 토크 6행에만 있는데(Cor.1)
                       그 6행이 각도 오차에 지배된다
                    -> 링크가 길수록 억압이 심해져(p=3 22배 -> p=4 4.2만배)
                       부위 열이 나란해진다 (p=6 에서 0.5 deg)
                    -> 남는 방향이 정리 2의 영공간에 가까워진다
                    (상세: 7-d '결과 분석')
   D-4  실용=물리   p>=4 는 마찰 힌지로 제작 불가
```

> **되든 안 되든 D-1·D-3·D-4 는 그대로이고 D-2 의 숫자만 바뀐다.**

#### E 에 반드시 넣을 것 — **시뮬레이터 재생 검증** ★

논문이 "sim-ready", "faithful in dynamics" 를 주장하는데 지금 재는 것은

## 6. 아직 본문에 안 들어간 것 — **반드시 추가**

### Method D 에 넣을 문단 (새 발견)

> 미지수로 함께 푼 것은 잔차를 잴 때도 반영해야 한다. TLS 가 맞춘 모형은
> `y ≈ A(θ+δ)ρ` 인데 잔차를 `y − A(θ)ρ` 로 재면 TLS 가 찾아낸 각도 보정량이
> 통째로 잔차로 잡힌다. 그러면 팽창이 **79배**까지 뛰고, 추정이 이미 목표를
> 넘었는데도 정지 조건이 만족되지 않는다.
>
> ```
>            팽창 배율        보고 반폭        실제 오차
>   p=4    79.3 -> 1.05    89.17% -> 1.18%     0.28%
>   p=5    94.3 -> 1.13   156.10% -> 1.87%     0.89%
> ```
>
> 오차변수 추정기와 잔차 기반 정지 조건을 함께 쓸 때 구조적으로 빠지는
> 함정이다. 코드는 `design_core.residual_scale` 로 고쳤다.

### 같은 성격의 두 번째 발견 — TLS 반복 상한

`tls_map` 의 `max_nfev` 가 400 으로 고정돼 있었다. 미지수는 `P + R*J` 로
라운드에 비례해 늘고 수치 미분이라 야코비안 한 번에 미지수 개수만큼 평가가
드는데, 상한은 고정이었다.

```
   p    미지수   상한 400 : nfev  오차%   |  상한 해제 : nfev  오차%
   4      52         20      0.25   |         20      0.25
   6      86        400     13.36   |        547      1.11    <- 12배
   8     120        166      4.60   |        166      4.60    <- 상한 문제 아님
```

**p=6 은 547 회면 수렴하는데 400 에서 잘리고 있었다.** `max_nfev=None` 로
바꾸면 scipy 가 `100*n` 을 쓴다 — 문제 크기에 맞춰 준다.

> **두 발견의 공통점**: 부위가 2~3 개일 때는 문제가 안 드러났다가, 부위가
> 늘면서 조용히 부족해진 설정들이다. **"n-link 가 안 된다" 의 상당 부분이
> 정보 한계가 아니라 이런 설정 문제였다.**

### 변경 4. 목표 반폭을 링크 수에 따라 정한다 ★★ — 가장 중요

**단순히 1 % → 2 % 로 올리는 것이 아니다.** 그러면 "편한 대로 정했다" 로
읽힌다. **목표를 예측해서 쓰는 것**으로 만들어야 한다.

#### 근거 — 정리 1의 따름결과

`M(θ)` 에 밀도가 없다(Cor. 1). `R_eff` 에만 들어오는데 그건 저울에서 얻은
사전분포로 대신할 수 있다. **그래서 렌치를 한 번도 안 재고 반폭 궤적을 예측할
수 있다.** 실제로 확인했다.

```
   반폭 [%]        R1       R2       R3       R5       R8
   p=3  예측     17.04     0.33     0.31     0.27     0.21
        실제     36.86     0.45     0.43     0.35     0.27
   p=4  예측    131.36    23.36     0.67     0.59     0.50
        실제    434.86    27.50     1.42     1.26     1.16
   p=5  예측    154.73    28.71    18.45     3.99     1.90
        실제    414.71   105.52    46.45     7.24     2.43
```

**예측이 실제의 1.4~2배 낙관적이지만 모양과 자릿수가 맞고, 항상 아래에
있다 — 즉 달성 가능 정밀도의 하한이다.** 측정 전에 계산된다.

#### 그래서 목표를 이렇게 정당화한다

```
   ① 운영 제약을 먼저 정한다
      사람이 관절을 맞추므로 한 라운드가 1~2 분. 실용 예산은 약 10 자세.

   ② 그 예산으로 달성 가능한 정밀도를 형상에서 계산한다
      반폭 ≈ C(p) / sqrt(R),  C 는 재구성 형상 + 저울값만으로 계산됨

   ③ 목표를 그 값으로 둔다
```

**목표는 우리가 고른 것이 아니라 (운영 예산 + 물체 형상) 이 정한 것**이 된다.
그리고 이것 자체가 실용적 기여다 — **"이 물체를 이 예산으로 재면 어느 정도
정밀도가 나오는지 측정 전에 알 수 있다."**

#### 왜 링크가 늘면 목표가 느슨해져야 하는가 (본문에 쓸 분석)

```
   ① rank 천장 (Prop 1)      한 자세는 최대 4 개. 부위가 늘면 자세가 더 필요.
                              이건 덧셈 (R >= ceil((P-1)/3))

   ② 그런데 정밀도는 더 빨리 나빠진다. 왜?
      마지막까지 남는 방향이 **이웃 부위의 밀도 차이** 이고, 이는 Prop 2 의
      영공간에 가깝다. 이웃 부위는 관절 하나로만 갈라지므로, 어떤 자세에서도
      함께 움직이는 정도가 크다.

   ③ 부위가 늘면 그런 '이웃 쌍' 이 늘어난다.
      반폭 ≈ C(p)/sqrt(R) 에서 C 가 부위마다 약 2 배씩 커진다.
      필요 라운드는 C^2 이므로 약 4 배씩.

   ④ 게다가 재구성이 질량에 2~3 % 를 기여한다
      (부피 5 % -> 1.64 %,  도심 1 mm -> 2.37 %)
      **그보다 낮은 목표는 갖고 있지 않은 정밀도를 인증하려는 것이다.**
```

**②가 핵심이다.** rank 는 덧셈으로 늘고 정밀도는 곱셈으로 나빠진다 —
`Remark (necessary, not sufficient)` 의 정량적 내용이 바로 이것이다.

### 최종 수치 ★ — 목표 2 %, 링크 길이 무작위, **seed 8** (총 2시간 48분)

`figures/nlink_final.json` / `nlink_final.png`

```
    p   미지수  하한R   수렴    라운드 범위        부위 질량오차 % (평균/최악)
   ───────────────────────────────────────────────────────────────────────
    2     3      1     8/8     1~1  (중앙 1)       0.17 / 0.43     하한 일치
    3     5      2     8/8     2~2  (중앙 2)       0.10 / 0.29     하한 일치
    4     7      2     8/8     3~4  (중앙 3)       0.26 / 0.44     하한 +1
    5     9      3     8/8     7~15 (중앙 9)       0.35 / 0.54
    6    11      4     4/8    15~24 (중앙 17)      1.25 / 3.50     절반만
```

**읽는 법 — 논문에 쓸 세 가지**

**① p=2·3 은 편차가 0 이다** (1~1, 2~2). 링크 길이가 서로 다른 물체 8개가
**전부 정확히 하한에 끝난다.** 우연이 아니라 구조적이라는 강한 증거다.
*"predicted number of configurations is met with equality"* 를 여기서 쓴다.

**② p=4 는 하한+1 로 좁게 붙는다** (3~4). *"within one of the bound"*.

**③ p=5 부터 물체에 따라 갈린다** (7~15). p=6 은 절반만 수렴(4/8).
**이것이 무작위 길이로 바꾼 덕에 보이는 결과다.** 고정 길이였다면 "p=6 은
안 된다" 한 줄로 끝났을 것을, 이제 **"난이도는 부위 개수만이 아니라 물체의
비율이 정한다"** 고 말할 수 있다.

**④ 인증은 보수적이다.** 목표가 2 % 인데 실제 질량 오차는 p<=5 에서
0.10~0.35 % 다 — **약 6 배 보수적**이다. 정지 조건이 안전한 쪽으로 틀린다는
증거이고, 논문에 그대로 쓸 수 있다.

**seed 4 와의 비교** (재현성 확인)

```
    p        seed 4        seed 8
    2        1 (4/4)       1 (8/8)     동일
    3        2 (4/4)       2 (8/8)     동일
    4        3 (4/4)       3 (8/8)     동일
    5        8 (4/4)      10 (8/8)     중앙값 이동
    6       20 (2/4)      18 (4/8)     비율 유지
```

**p=2~4 는 seed 를 두 배로 늘려도 안 흔들린다.** p=5·6 은 표본이 늘면서
중앙값이 움직였으므로, 논문에는 **중앙값이 아니라 범위(min~max)와 수렴
비율을 함께** 적는 것이 정직하다.

### 목표별 필요 라운드 (보조 표, seed 2, 30라운드 예산)

```
    p    0.5%     1%    1.5%     2%     3%     5%
    3      4       2      2       2      2      2
    4      —       —      3       3      3      3
    5      —       —      —       —     11      5
    6      —       —      —       —      —     13
```

**무릎(knee)이 p 에 따라 오른쪽으로 밀린다** — p=3 은 0.5 % 아래, p=4 는
1~1.5 % 사이, p=5 는 2~3 % 사이, p=6 은 3~5 % 사이. **벽이 아니라 점진적
저하다.** 목표를 링크 수에 따라 정해야 하는 이유가 이 표다.

> 이 보조 표는 seed 2 개짜리다. 본문에 넣으려면 seed 를 늘려 다시 재야 한다.
> 최종 표(위, seed 8)가 주 결과이고 이것은 목표 선택의 근거로만 쓴다.

### 결과 분석 — **본문 IV-D 에 그대로 들어갈 논지** ★★

수치만으로는 부족하다. **왜 그런지**가 논문의 값어치다. 아래가 그 분석이고,
전부 측정으로 뒷받침된다.

#### 주장: 부위가 늘수록 반폭이 커지는 것은 **다관절 물체의 물리적 성질**이다

> 부위를 구별하는 정보는 오직 **토크 채널**에 있다(Cor. 1 — 힘 채널은 저울과
> 중복이라 부위를 구별하지 못한다). 그런데 링크가 길어질수록 관절 하나가
> 렌치에 미치는 영향이 커져 **각도 불확실성이 바로 그 토크 채널을 지배**하게
> 된다. 그 결과 회귀행렬의 부위 열이 서로 나란해지고, 남는 미결정 방향은
> 정리 2가 규정한 영공간 — 총질량과 1차 모멘트를 보존하는 재배치 — 에
> 가까워진다.

#### 근거 1. 부위 열이 실제로 나란해진다

백색화한 회귀행렬에서 두 부위 열이 이루는 각도 (무작위 자세 40개 평균):

```
    p    이웃 쌍    비이웃 쌍
    2     47.0 deg      —
    3     36.8         51.8
    4     10.9         18.5
    5      1.6          3.4
    6      0.5          1.1        <- 사실상 나란함
```

**이웃뿐 아니라 모든 부위 쌍이 그렇다.** p=6 에서 0.5 도면 수치적으로
구별이 거의 불가능하다.

#### 근거 2. 왜 나란해지는가 — 채널 구조

```
   힘 행    모든 부위 열이 g_hat 방향으로 **원래 나란하다**
            (Cor. 1: 힘 채널은 저울과 중복)
   토크 행  여기서만 부위가 갈린다 (18행 중 6행. 나머지 3행은 외적으로 죽음).
            그런데 여기가 각도 오차에 지배되는 자리다
            R_eff/R_sensor: p=3 에서 22배 -> p=4 에서 41,690배
   백색화   잡음이 큰 토크 행을 눌러버린다
            -> 남는 것은 원래 나란했던 힘 행 -> 열이 나란해진다
```

#### 근거 3. 링크가 길어질수록 그 억압이 심해진다

```
   각도잡음 / 센서잡음 (토크 행)
      p=3    130 만 배
      p=8   2535 만 배      <- 20 배 증가
```

링크가 늘면 하류 질량과 모멘트팔이 커져 **관절 1도가 렌치를 더 크게
바꾼다.** 그것이 곧 각도 오차 기여가 커진다는 뜻이고, 토크 행이 더 눌린다.

#### 이 설명이 "사슬이 되말려서" 보다 나은 이유 세 가지

```
   ① 이론과 직결   정리 1(힘 채널 중복)과 정리 2(영공간)가 그대로 쓰인다
   ② 일반적        특정 물체 모양이 아니라 **직렬 사슬이면 다 그렇다**
                   되말림은 우리 시험 물체의 우연한 성질이었다
   ③ 왜 못 고치는지도 설명
                   더 좋은 탐색으로 안 됨 (꼭짓점·무작위가 8~40배 나쁨)
                   더 좋은 F/T 센서로 안 됨 (토크 잡음은 각도가 지배)
                   -> **각도 정밀도만이 유일한 지렛대**
```

#### 물체별 편차의 원인 — **잡음이지 물체가 아니다** (해결됨)

p=5 에서 7~15 라운드, p=6 에서 4/8 수렴이라는 편차를 무엇이 정하는지 갈랐다.
**물체와 잡음을 분리해서 각각 8번씩 돌렸다.**

```
   p=5, 목표 2 %, 30라운드 예산

   A) 물체 고정 + 잡음만 변화 :  [11  8 10  5  7 17 13 19]   범위 5~19,  σ=4.5
   B) 물체 변화 + 잡음 고정   :  [11 15  9  8  8  8 13 17]   범위 8~17,  σ=3.3
```

**같은 물체인데 잡음만 바꿔도 5~19 라운드로 4 배 벌어진다.** 물체를 바꿨을
때보다 오히려 편차가 크다. **즉 편차는 측정 잡음이 만들지 물체가 만들지
않는다.**

이것이 앞서 기하학적 예측자들이 전부 실패한 이유다 — **예측할 대상이 애초에
없었다.**

```
   단순 길이비(가장 비슷한 이웃 쌍)  ->  상관 일관되지 않음
                                        p=4 +0.46 / p=5 −0.37 / p=6 −0.17
   정보행렬 예측(측정 전 반폭)        ->  상관 +0.16
```

**논문에 쓸 문장**

> The spread in round count is dominated by the measurement-noise realization
> rather than by the object's proportions: holding the object fixed and varying
> only the noise gives 5–19 rounds ($\sigma=4.5$), while varying the object with
> the noise fixed gives 8–17 ($\sigma=3.3$). Reporting a median alone would
> therefore be misleading; we report the range and the fraction that converged.

**따라서 표에 중앙값만 적으면 안 된다.** 범위(min~max)와 수렴 비율을 함께
적어야 하고, 그 이유가 이 측정이다.

## 8. 함정 — 같은 실수를 반복하지 않도록

이 연구를 검토하면서 **세 번 틀린 결론을 내고 정정했다.** 새 대화에서 같은
길을 다시 가지 않도록 적어 둔다.

| 틀린 결론 | 실제 | 어떻게 갈렸나 |
| --- | --- | --- |
| "D-최적이 엉뚱한 것을 최대화한다" | **D 가 대안보다 8~40배 낫다** | 자세 200개를 `SIGMA0` 고정으로 비교해서 1라운드 상황만 봤다. 폐루프에서 D 는 사후분포에 **적응**한다 |
| "자세가 반복돼서 나쁘다" | 다양성을 더해도 안 좋아짐 | seed 4개 비교의 잡음을 과잉 해석했다 |
| "p≥5 는 어떤 예산에서도 안 된다" | 예산이 짧았고, **정지 조건 버그**가 컸다 | 12~30라운드로 판정했다. 실제 필요는 수십~수백 |
| "1만 6천 라운드 필요" | 수백 라운드 | R=8 의 나쁜 값에서 외삽했다 |

**교훈**: 폐루프 알고리즘을 단일 라운드 지표로 판단하지 말 것. seed 를 충분히
쓸 것. 그리고 "안 된다" 는 결론 전에 **추정 오차와 보고 반폭을 따로 볼 것** —
둘이 100배 차이 날 수 있다.

# 신규성 감사 — 방향 전환 전 최종 검토

> **질문 둘**: (1) 이론 기여가 논문 방향을 바꿀 만큼 명확한가?
> (2) 기존에 이런 연구가 정말 없었나?
>
> **결론 먼저**: 이론은 **있지만 생각보다 좁습니다.** 그리고 방향을 이론 쪽으로
> 옮기면 **더 약한 신규성 쪽으로 가게 됩니다.** 재배치는 권하되 전환은 권하지 않습니다.

---

## 1. 감사 결과 — 요소별 선행 여부

| 요소 | 선행연구 | 판정 |
| --- | --- | :---: |
| 정지 중력 측정 = 질량 + 무게중심(숫자 4개) | Atkeson·An·Hollerbach 1986, 교과서 | **기존** |
| **자세를 바꿔가며 부위별 질량을 푼다** | **반응판(reaction board) 기법 — 생체역학** | **기존** ★ |
| D-최적으로 자세를 고른다 | Gautier·Khalil 1992, Swevers 1997, 로봇 캘리브레이션 문헌 | **기존** |
| 관절 구조의 관성 파라미터 식별성 기하 특성화 | Wensing·Niemeyer·Slotine, IJRR 2024 (RPNA) | **기존** (범위 다름) |
| 회귀행렬 오차(EIV)를 TLS 로 | IDIM-TLS 계열 | **기존** |

| **실측 기반 관절체 부위별 밀도 → 3DGS sim-ready asset** | 못 찾음 | **신규 (명확)** |

## 2. ★ 새로 찾은 것 — 반응판(reaction board) 기법

생체역학에서 **수십 년 된 표준 기법**입니다. 문헌의 표현을 그대로 옮기면:

> *"solve for segment weights by measuring the changes in force plate readings
> as limbs are repositioned, exploiting the static equilibrium principle."*

**우리 방법의 핵심 메커니즘과 정확히 같습니다.**

```
   반응판 기법        사람이 판 위에 눕는다
                     → 팔다리 자세를 바꾼다
                     → 힘판 값의 변화를 본다
                     → 분절(segment)별 질량을 푼다

   우리              로봇이 물체를 잡는다
                     → 관절 자세를 바꾼다
                     → 손목 F/T 값의 변화를 본다
                     → 부위(part)별 질량을 푼다
```

### 이것이 뜻하는 것

**"관절을 접는 것이 부위별 질량을 드러내는 유일한 수단"이라는 통찰은 새롭지
않습니다.** 생체역학은 이걸 1900년대부터 실무로 써 왔습니다.

> 앞서 제가 *"관절이 필요조건임을 증명한 것이 가장 값어치 있는 문장"* 이라고
> 말씀드렸는데, **그 메커니즘 자체는 기존 지식입니다.** 정정합니다.

### 그래도 남는 것

생체역학은 자세를 **경험적으로** 고릅니다 — 문헌에 "세 자세", "아홉 자세"가
나오지만 **왜 그 개수인지에 대한 유도가 없습니다.** 찾아본 범위에서
**식별성 분석(rank 상한, 영공간 특성화, 최소 자세 개수)은 없습니다.**

```
   생체역학 :  "자세를 바꾸면 분절 질량을 풀 수 있다"     (기법으로서 확립)
   우리     :  "왜 한 자세로는 4개까지인지,
                무엇이 안 보이는지,
                최소 몇 자세가 필요한지"                 (형식화)
```

**즉 우리 기여는 '메커니즘 발견'이 아니라 '알려진 기법의 형식화'입니다.**
작지만 없지는 않습니다. 다만 이걸 논문의 **주장 전체**로 세우면 위험합니다.

## 3. 그래서 방향 전환이 위험한 이유

신규성을 강도순으로 줄 세우면 이렇습니다.

```
   강함  ①  실측 기반 관절체 부위별 밀도 → sim-ready asset
             선행 없음. VLM·생성모델·수작업으로 물성을 넣는 연구만 있음
                                    │
   중간  ②  이 설정에서의 능동 자세 선택
             도구는 전부 기존. 설정(설계변수가 물체 형상)이 새로움
                                    │
   약함  ③  식별성 분석 (rank 4, 자세 개수 하한)
             고전 사실의 형식화. 메커니즘은 반응판 기법으로 기존
```

> **역설**: 부피 오차 때문에 ① 을 약화시키고 ③ 으로 무게를 옮기려 하시는데,
> **① 이 가장 강하고 ③ 이 가장 약합니다.** 방향 전환은 강한 카드를 버리고
> 약한 카드를 드는 것이 됩니다.

### 그런데 부피 오차는 ① 을 위협하지 않습니다

① 의 주장은 **절대적이 아니라 상대적**입니다 — "추측보다 측정이 낫다".

```
   VLM 기반 baseline (PUGS, SiPhy)  :  부위 질량 오차  수십 ~ 수백 %
   우리 (부피 오차 10% 포함)         :  부위 질량 오차  약 6 %
```

**부피가 10% 틀려도 측정이 추측을 압도합니다.** ① 은 멀쩡합니다.
"완벽한 asset 을 만든다"고 쓰지 않고 **"추측 대신 측정한다"** 고 쓰면
부피 오차는 주장을 건드리지 못합니다.

## 4. 권고 — 전환이 아니라 재배치

| | 하지 말 것 | 할 것 |
| --- | --- | --- |
| **논문의 주어** | "수학적 분석 논문" 으로 전환 | **"측정 기반 real2sim"** 유지 |
| **이론의 위치** | 유일한 기여 | **1번 기여로 올리되, 유일하지 않게** |
| **부피 오차** | 감추거나 "보정했다"로 얼버무림 | **정량화된 가정**으로 명시 (도심 1mm → 2.4%, 부피 10% → 6%) |
| **"관절이 필요조건"** | "우리가 증명했다" | **"알려진 요구를 정밀화했다"** + 반응판 인용 |

지금 확정한 contribution 4개는 **이 권고와 이미 일치합니다.**
1번이 분석, 3번이 파이프라인이라 무게가 나뉘어 있습니다. **바꿀 필요가 없습니다.**

### 반드시 추가할 인용

```
   반응판 기법 (생체역학)     — 자세 변경으로 분절 질량을 푸는 선행 기법
   Atkeson·An·Hollerbach 1986 — 정적 측정의 4개 한계
   Wensing IJRR 2024          — 관절 구조 식별성 (추가 완료)
   Gautier'92 / Swevers'97    — D-최적 여기설계 (추가 완료)
```

**반응판을 인용하지 않으면 위험합니다.** 생체역학을 아는 리뷰어가
*"이건 reaction board method 아닌가"* 라고 물으면 답이 없습니다.
먼저 인용하고 차이를 말하면 오히려 강해집니다.

**Related Work 에 넣을 문안:**

> In biomechanics, segment masses have long been estimated by repositioning a
> subject's limbs on a reaction board and reading the change in support
> reactions---the same static principle we exploit. That literature selects
> postures empirically, however, and does not characterize how many
> configurations a given segmentation requires, which is what our analysis
> supplies; nor does it address a robot choosing configurations online under
> grasp and collision constraints.

## 5. 그래서 (1) 에 대한 답

> **"이론 기여가 논문 방향을 바꿀 만큼 명확한가?"**
>
> **아니오.** 기여로 세울 만은 하지만, 논문을 그쪽으로 재편할 만큼은 아닙니다.
> 메커니즘이 기존이고 형식화만 새롭기 때문입니다.
>
> **대신 지금처럼 1번 기여로 두는 것이 정확합니다.** 그러면
> "측정 기반 real2sim(강함) + 그 설정의 형식화(새로움)" 라는 두 다리로 서게 되어,
> 리뷰어가 어느 한쪽을 흔들어도 논문이 안 넘어집니다.

## 6. (2) 에 대한 답

> **"기존에 이런 연구가 정말 없었나?"**
>
> **재료는 전부 있습니다.** 반응판(메커니즘), Atkeson(4개 한계),
> Swevers/Gautier(D-최적), Wensing(식별성), IDIM-TLS(EIV), Hausman(능동 탐색).
>
> **없는 것은 둘입니다.** (a) 이 설정에서의 자세 개수 하한과 rank 특성화,
> (b) **실측 기반 관절체 부위별 밀도를 3DGS 자산에 기록하는 파이프라인.**
> (b) 가 더 확실하고 더 강합니다.

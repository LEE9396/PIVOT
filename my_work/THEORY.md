# Part I — 무엇을 해야 하는가

## T0. 출발점: 측정 모형을 기호로 정리 (이미 코드에 있음)

부위 `P` 개, 부위 `i` 의 부피 `V_i` (복원에서 나옴), 밀도 `ρ_i` (미지수).
물체를 base 에서 파지하고, 손목 센서 프레임 `S` 에서 관절형상 `θ` 일 때 부위 `i` 의
도심을 `c_i(θ)` 라 합니다 (FK + 형상에서 나오며 **밀도와 무관**).

중력 단위벡터 `ĝ` (프레임 S 기준), 중력가속도 `g` 에서 정지 렌치는

```
f = g (Σ_i V_i ρ_i) ĝ
τ = g Σ_i V_i ρ_i (c_i(θ) × ĝ)
```

여기서 두 기호를 정의합니다. **이 두 개가 이 문서 전체의 주인공입니다.**

```
V    = (V_1, ..., V_P)ᵀ                        ∈ R^P        부피 벡터
C(θ) = [ V_1 c_1(θ), ..., V_P c_P(θ) ]         ∈ R^{3×P}    부피가중 도심 행렬
```

`c × ĝ = −[ĝ]ₓ c` 를 쓰면 회귀행렬은

```
A(θ, ĝ) = g [  ĝ Vᵀ        ]   ∈ R^{6×P}
            [ −[ĝ]ₓ C(θ)   ]
```

**[density_id_drake.py:180-188](density_id_drake.py#L180-L188) 의 `regressor()` 가
정확히 이것입니다.** (`force_rows = G_ACC * outer(g_hat, VOLUMES)`,
`torque_rows = G_ACC * (cross(c, g_hat).T * VOLUMES)`)

센서 잡음은 `R = diag(σ_f² I₃, σ_τ² I₃)` — **블록 등방성**입니다
([density_id_drake.py:72](density_id_drake.py#L72) 의 `R_EPS_DIAG`).
이 등방성이 아래 모든 결과의 전제입니다. **반드시 논문에 가정으로 명시하십시오.**

## T1. 정리 1 — 정보행렬의 닫힌 형태 (반나절)

**할 일**: 아래를 전개해서 논문 Method 에 넣고, 수치로 검증합니다.

중력 방향 하나에 대한 정보 기여는

```
A(θ,ĝ)ᵀ R⁻¹ A(θ,ĝ)
  = g² [ (1/σ_f²) V (ĝᵀĝ) Vᵀ  +  (1/σ_τ²) C(θ)ᵀ [ĝ]ₓᵀ[ĝ]ₓ C(θ) ]
  = g² [ (1/σ_f²) V Vᵀ  +  (1/σ_τ²) C(θ)ᵀ (I − ĝĝᵀ) C(θ) ]
```

`‖ĝ‖=1` 이므로 `ĝᵀĝ = 1`, 그리고 `[ĝ]ₓᵀ[ĝ]ₓ = −[ĝ]ₓ² = I − ĝĝᵀ` 를 썼습니다.

방향 `K` 개 `{ĝ_k}` 를 쌓으면

```
M(θ) = g² [ (K/σ_f²) V Vᵀ  +  (1/σ_τ²) C(θ)ᵀ ( K·I − Σ_k ĝ_k ĝ_kᵀ ) C(θ) ]
```

> ### 정리 1 (삼면체 회전 불변성)
> `{ĝ_1, ĝ_2, ĝ_3}` 가 **직교정규 삼면체**이면 `Σ_k ĝ_k ĝ_kᵀ = I` 이므로
> ```
> M(θ) = g² [ (3/σ_f²) V Vᵀ  +  (2/σ_τ²) C(θ)ᵀ C(θ) ]
> ```
> 이고, 이 값은 **삼면체를 통째로 어떻게 회전시켜도 변하지 않는다.**

**증명은 위 두 줄이 전부입니다.** 항등분해 `Σ ĝĝᵀ = I` 하나면 끝납니다.

**이것이 하는 일**: 설계공간을 `Θ × SO(3)` 에서 `Θ` 로 붕괴시킵니다. 즉
*"어느 방향으로 기울일까"는 고민할 필요가 없고, **오직 관절 형상 θ 만이
설계 변수다"* 를 증명합니다. 지금은 [ALGORITHM.md](ALGORITHM.md) §15 에
`study_tilt.py` 의 실험 관찰로만 적혀 있는데, 증명이 붙으면 **실험이 정리의
수치 검증**으로 격상됩니다.

### 파생 결과 두 개 (공짜로 따라오고, 둘 다 실용적으로 중요)

**(1a) `M(θ)` 에 밀도 `ρ` 가 없습니다.**
정보행렬은 `V` 와 `C(θ)` — 즉 **형상만으로** 결정됩니다. 그러므로 센서 잡음만
있는 세계에서는 **최적 형상 수열을 오프라인에서 전부 미리 계산할 수 있습니다.**
폐루프가 필요 없습니다.

그런데 [design_core.py:52-58](design_core.py#L52-L58) 의 `effective_cov()` 는
`R_eff = R_sensor + J Σ_θ Jᵀ` 를 쓰고, `J = ∂(Aρ)/∂θ` 는 **ρ 에 의존합니다.**
따라서:

> **각도 오차가 없으면 설계는 개루프로 충분하다. 폐루프가 필요한 유일한 이유는
> 설계 변수 θ 자체가 오차를 갖고 측정되기 때문이다.**

이건 아키텍처 선택(왜 closed-loop 인가)에 대한 **정리에서 나온 답**입니다.
리뷰어가 "왜 그냥 미리 계산하지 않나"라고 물으면 이 한 문장이 답입니다.

**(1b) 힘(force) 채널은 저울 이상의 정보를 주지 않습니다.**
힘 기여는 `(K/σ_f²) V Vᵀ` — **`ĝ` 와 무관하게 항상 `V` 방향 하나뿐**이고,
이는 저울이 재는 `Vᵀρ = 총질량` 과 정확히 같은 방향입니다. 따라서

> **부위별 정보는 전부 토크 채널에서 나온다.**

실용적 함의: 구속 사양은 `σ_F` 가 아니라 **`σ_τ` (AFT200 의 0.003 N·m)** 입니다.
센서 선정·타어링 정밀도 논의를 여기에 걸면 됩니다.

## T2. 정리 2 — 식별성과 퇴화 (반나절)

> ### 정리 2 (단일 형상의 rank 상한)
> 임의의 방향 개수 `K` 와 **임의의 방향 배치**에 대해,
> ```
> rank M(θ)  ≤  rank(V Vᵀ) + rank(C(θ)ᵀ G C(θ))  ≤  1 + rank C(θ)  ≤  1 + min(3, P)
> ```
> 여기서 `G = K·I − Σ_k ĝ_kĝ_kᵀ ⪰ 0`. 즉 부위가 3개 이상이면
> **어떤 단일 형상에서도 rank 는 4 를 넘지 못한다.**

> ### 따름정리 2.1 (강체 한계) ← **가장 값어치 있는 문장**
> 물체가 강체이면(θ 고정) 중력 방향을 **몇 개를 쓰든, 몇 번을 반복하든**
> `rank M ≤ 4` 이다. 즉 식별 가능한 밀도 조합은 최대 4개이며, 부위가 5개 이상인
> 물체는 **추가 사전지식 없이는 원리적으로 식별 불가능하다.**

> ### 따름정리 2.2 (영공간의 물리적 의미)
> 직교정규 삼면체에서 `M = a·VVᵀ + b·CᵀC` (a,b>0) 이므로
> `Mu = 0 ⟺ uᵀMu = 0 ⟺ Vᵀu = 0 이고 C(θ)u = 0`. 따라서
> ```
> null M(θ) = { u : Σ_i u_i V_i = 0  이고  Σ_i u_i V_i c_i(θ) = 0 }
> ```
> **총질량과 손목 기준 1차 모멘트를 동시에 보존하는 질량 재분배는 보이지 않는다.**

**이것이 하는 일**: "왜 안 보이는가"에 대한 **완전한 특성화**입니다.
정지 렌치는 질량 분포의 **0차 모멘트(총질량)와 1차 모멘트(CoM)만** 봅니다.
그 둘을 보존하는 재분배는 물리적으로 구별 불가능합니다 — 알고리즘의 한계가
아니라 **측정 물리의 한계**입니다.

그리고 **관절을 접는 것이 왜 새로운 정보 채널인지**가 여기서 나옵니다:
`θ_1` 에서 보이지 않던 재분배 `u` 가 `θ_2` 에서는 `C(θ_2)u ≠ 0` 이 되어
보이기 시작합니다. **관절 운동은 영공간을 회전시키는 유일한 수단입니다.**

### ⚠ 반드시 고쳐야 할 모순

[ALGORITHM.md](ALGORITHM.md) §6 은 퇴화를 *"관절 축이 중력과 나란해지면 그
아래 부위의 비틀림이 0 이 되어 안 보인다"* 로 설명합니다. **이 설명은 정리 1과
모순됩니다** — 직교 삼면체를 쓰는 순간 중력 방향은 정보량에 영향을 주지
못하기 때문입니다. (단일 방향 측정이었다면 맞는 설명입니다.)

올바른 퇴화 조건은 **따름정리 2.2** 입니다. 리뷰어가 이 불일치를 발견하면
정리 1의 신뢰도까지 같이 떨어집니다. **문서와 논문 양쪽에서 고치십시오.**

## T3. 정리 3 — 라운드 수 하한과 설계 목적함수 (반나절)

> ### 정리 3 (라운드 하한)
> 형상 `θ_1, ..., θ_R` 에서 측정하면 `M_R = Σ_r M(θ_r)` 이고
> ```
> rank M_R  ≤  1 + rank [ C(θ_1) ; ... ; C(θ_R) ]  ≤  1 + min(3R, P)
> ```
> 따라서 전체 식별(rank = P)에는 **`R ≥ ⌈(P−1)/3⌉`** 회의 서로 다른 형상이 필요하다.

> ### 따름정리 3.1 (설계 문제의 정체)
> `M(θ)` 가 ρ 와 무관하므로, 능동 설계란 **쌓인 `C(θ_r)` 들의 행공간이 서로
> 얼마나 빨리 상보적으로 `R^P` 를 채우는가**를 최대화하는 순수 기하 문제이다.

> ### 따름정리 3.2 (직렬 사슬의 n-link 법칙) ← **일반화의 최종 형태**
> 링크 `p` 개가 직렬로 이어지고 **관절마다 힌지가 하나씩** 달린 사슬에서는
> 추정 벡터의 길이가 `P = p + (p−1) = 2p − 1` 이므로
> ```
>     R  ≥  ⌈ (2p − 2) / 3 ⌉
> ```
> 이다. 이 값이 실물 두 물체의 관측 라운드 수를 **정확히 재현한다.**
> ```
>   p=2 (2-link):  P=3   하한 1   관측 1  ✓
>   p=3 (3-link):  P=5   하한 2   관측 2  ✓
>   p=4         :  P=7   하한 2
>   p=5         :  P=9   하한 3
>   p=6         :  P=11  하한 4
>   p=7         :  P=13  하한 4
>   p=8         :  P=15  하한 5
> ```

### ⚠ `nlink.py` 에 힌지가 빠져 있던 문제 (수정 완료)

합성 사슬 생성기 [nlink.py](nlink.py) 는 관절에 `hinge_mass_kg` 를 주지 않아
**힌지가 없는 물체**를 만들고 있었습니다. 그래서 합성 `P=3` 의 미지수가 3개로,
실물 3-link 의 5개와 달랐습니다 — **P=2..8 스윕이 실물보다 쉬운 문제를
재고 있었던 것**입니다.

관절마다 실측 힌지 41 g 을 붙이도록 고쳤고, 그 결과 합성 사슬이 실물을
정확히 재현합니다.

```
              미지수   단일형상 rank   하한R   관측R
  실물 2link      3          3           1      1
  합성 P=2        3          3           1      1   ← 일치
  실물 3link      5          4           2      2
  합성 P=3        5          4           2      2   ← 일치
```

이제 P=4..8 은 **같은 규칙을 이어붙인 확장**이므로, 스윕 결과를 실물 결과와
나란히 놓고 읽을 수 있습니다.

### ⚠ `study_criterion.py` 의 정지 판단이 정식 루프와 달랐던 문제

`study_criterion.closed_loop` 은 자체 루프를 갖고 있으면서 정지 판단에
`half.max()` 를 써서 **힌지 행까지 최대값에 넣고** 있었습니다. 힌지는 사전분포
반폭이 2 % 로 고정이라, 목표가 1 % 면 부위가 다 수렴해도 루프가 안 끝납니다.
([design_core.py:489](design_core.py#L489) 의 `stopping_width()` 가 정확히 이
실패 모드를 막으려고 있는 함수인데 쓰이지 않고 있었습니다.)

힌지가 없던 동안에는 드러나지 않던 문제입니다. 위 nlink 수정으로 드러났고,
정식 루프 [design_core.closed_loop](design_core.py#L522) 로 바꾸면 사라집니다
(실물 3link: 12라운드 미수렴 → **2라운드 수렴**).

### 실측 — 커스텀 물체 두 개에서 하한이 **관측 라운드 수와 정확히 일치**합니다

[study_theory.py](study_theory.py) 가 저장소의 실제 물체를 `bind_object()` 로
물려서 잰 값입니다.

```
  2link      미지수 3   단일형상 rank 3 (상한 3)   라운드 하한 1   관측 1  ✓
  3link      미지수 5   단일형상 rank 4 (상한 4)   라운드 하한 2   관측 2  ✓
  desklamp   미지수 3   단일형상 rank 3 (상한 3)   라운드 하한 1   관측 2
```

**3-link 가 결정적입니다.** 미지수가 5개(부위 3 + 힌지 2)인데 단일 형상의 rank 는
정리 2의 천장 4에 걸립니다. 즉 **한 형상에서는 원리적으로 다 풀 수 없고 최소
2 라운드가 필요**하며, 실제 폐루프도 정확히 2 라운드에서 끝납니다
([HANDOFF.md](../HANDOFF.md) §7). 2-link 는 미지수 3, rank 3 → 하한 1, 관측 1.

> **정리 3이 두 물체의 라운드 수를 정확히 예측합니다.** 이건 사후 설명이 아니라
> 형상 정보만으로 계산되는 값입니다 (`M(θ)` 에 ρ 가 없으므로 — 파생결과 1a).

**정직하게 같이 써야 할 것**: 이 하한은 **필요조건이지 충분조건이 아닙니다.**
desk lamp 는 하한이 1인데 실제로는 2 라운드가 걸립니다 — rank 는 1 라운드에
찼지만 한 방향의 반폭이 목표 위에 남기 때문입니다. 즉 실제 라운드 수는
rank 가 채워진 **다음부터는 조건수(conditioning)** 가 지배합니다.

**이 간극이 바로 논문의 실험 파트가 정량화할 대상입니다:**

```
rank 하한        → "언제 불가능한가"          (정리 3)
조건수 벽        → "언제 실용적으로 불가능한가"  (실험: P=2..8 × 각도정밀도 스윕)
그 사이의 간극   → 각도 측정 정밀도가 만든다     (연구의 핵심 실증 주장)
```

`P=6` 이 12 라운드에도 미수렴하는데 rank 하한은 2 라는 사실은 **실패가 아니라
"조건수 간극이 이만큼 크다"는 측정값**입니다. 이렇게 프레이밍하면 한계 섹션이
결과 섹션이 됩니다.

## T4. 수치 검증 — **이미 통과했습니다**

교수님도 리뷰어도 **"유도한 식이 실제 코드와 같은가"**를 반드시 묻습니다.
스크립트 하나로 답이 끝납니다.

```
① 닫힌 형태 일치     : 무작위 θ 200개에 대해
                       ‖ M_closed(θ) − A(θ)ᵀR⁻¹A(θ) ‖ < 1e-10   assert
② 삼면체 회전 불변성 : 무작위 R ∈ SO(3) 100개에 대해
                       ‖ M(θ, R·삼면체) − M(θ, 삼면체) ‖ < 1e-10  assert
③ rank 상한          : 무작위 θ 에서 rank M(θ) ≤ 4  assert  (P=5..8 물체)
④ 강체 한계          : θ 고정 + 중력방향 20개 → rank 여전히 ≤ 4  assert
⑤ 영공간             : null M(θ) 의 기저 u 에 대해
                       |Vᵀu| < 1e-12 이고 ‖C(θ)u‖ < 1e-12  assert
⑥ 라운드 하한        : nlink.make_spec(P) 로 P=2..8, 하한 ⌈(P−1)/3⌉ 과
                       실제 rank 도달 라운드 비교표
```

`nlink.py` 가 이미 P=2..8 물체를 만들어 주므로 새로 만들 것이 없습니다.

### 실제 검증 결과 ([study_theory.py](study_theory.py), 무작위 형상 300개)

```
[정리1] 닫힌형태 vs AᵀR⁻¹A        상대오차 최대 : 7.9e-16
[정리1] 삼면체 회전 불변성          상대오차 최대 : 7.9e-16
[정리2] rank − 4 의 최댓값 (P≥4)                : 0      ← 상한 성립
[정리2] 임의 K개 방향 일반 닫힌형태 상대오차 최대 : 5.6e-16
[정리2.2] 영공간 조건 위반량 최대                : 7.5e-14
```

**세 정리 모두 기계 정밀도로 성립합니다.** 유도가 맞습니다.

### 정리 3에 대한 추가 발견 — 하한은 generic 하게 **tight** 합니다

무작위 형상에서 누적 rank 를 재보니 상한 `1 + min(3R, P)` 가 **정확히 달성**됩니다.

```
  P=3   R=1: rank 3 (상한 4)   ← R=1 에 이미 full rank
  P=5   R=1: rank 4 | R=2: rank 5 (=P)
  P=6   R=1: rank 4 | R=2: rank 6 (=P)
  P=8   R=1: rank 4 | R=2: rank 7 | R=3: rank 8 (=P)
```

즉 `R ≥ ⌈(P−1)/3⌉` 는 느슨한 하한이 아니라 **generic 하게 달성되는 값**입니다.
`P=8` 조차 rank 만 보면 **3 라운드면 충분**합니다.

> ### 그래서 조건수 간극이 이 연구의 진짜 발견입니다
> rank 는 `P=8` 에 3 라운드라고 말하는데, 실제로는 `P=6` 이 **12 라운드에도
> 수렴하지 않습니다**([ALGORITHM.md](ALGORITHM.md) §12). 3-link 도 `R=1` 에 이미
> full rank 인데 실제로는 **2 라운드**가 걸립니다.
>
> **이 간극은 전부 조건수이고, 조건수는 각도 측정 정밀도가 만듭니다.**
> 정리가 "정보가 있다"고 말하는 것과 "그 정보를 실제로 뽑을 수 있다"는 것
> 사이의 거리를 정량화하는 것 — 그것이 T6 스윕이 측정할 대상입니다.

### laptop 의 GT 문제 — 기지 추 부착으로 우회

노트북은 분해하지 않으면 화면부/본체부 질량을 따로 못 잽니다. 절대 GT 대신
**부위 귀속(part attribution) 검증**을 하십시오.

```
1. 노트북 그대로 추정  →  m̂_lid , m̂_base
2. 화면부에 알려진 추 Δm = 50 g 부착
3. 다시 추정          →  m̂'_lid , m̂'_base
4. 검증 : (m̂'_lid − m̂_lid) ≈ 50 g   그리고   (m̂'_base − m̂_base) ≈ 0 g
```

**이게 절대 GT 보다 오히려 강한 증거입니다.** 절대값은 스캔 부피 오차와
섞이지만, 차분은 부피 오차가 상쇄되어 **"추정기가 질량을 올바른 부위에
귀속시키는가"만 순수하게** 시험하기 때문입니다. 정리 2.2 가 말하는
"재분배를 볼 수 있는가"를 직접 실험한 것이기도 합니다.

> 여유가 되면 desk lamp 에도 같은 delta 실험을 하십시오. 분해 GT(절대) +
> 추 부착(차분) 두 방식이 일치하면 검증이 거의 완결됩니다.

## 논점 1 — "그래서 뭐가 새로운데?" (기여의 위치)

먼저 **재료는 하나도 새롭지 않다고 먼저 인정하고 들어갑니다.** 이게 훨씬
설득력이 있습니다.

> "관성 파라미터 식별의 최적 여기설계는 Swevers 1997 이후 표준이고,
> 능동 탐색은 ASID 가 했고, 관절체 상호작용 지각은 Hausman 2015 가 했고,
> 부위별 관성 식별은 Sum of Its Parts 가 했습니다. **저희가 새로 만든 재료는
> 없습니다.**"

그 다음 위치를 정확히 찍습니다.

> "다만 기존 여기설계는 **전부 로봇 궤적 `q(t)` 를 설계 변수로 놓고, 물체는
> 고정된 단일 강체 페이로드**로 봅니다. 저희는 로봇이 준정적으로 중력 방향만
> 바꾸고, **정보는 물체 자신이 어떻게 접히느냐에서 나옵니다.** 설계 변수가
> `q(t)` 가 아니라 물체의 관절 형상 `θ` 입니다."

이 뒤집힘이 고전 설정에 **없던 세 가지**를 만듭니다. 이걸 나열합니다.

1. **θ 는 로봇이 구동하지 않습니다.** 마찰 유지 관절이라 사람이 맞춥니다.
   즉 *반(半)제어 설계변수* 입니다.
2. **설계변수 자체가 오차를 갖고 측정됩니다.** θ 를 비전으로 재므로 설계와
   추정이 결합됩니다. 고전 설계는 `q` 를 엔코더로 정확히 안다고 가정하므로
   이 결합이 아예 존재하지 않습니다.
3. **가용집합이 조작 가능성으로 정의됩니다.** θ 가 바뀌면 물체 형상이 바뀌어
   파지·IK·충돌·경로 존재가 전부 바뀝니다. 고전 설계에서 페이로드 형상은 고정입니다.

> "이 세 개가 동시에 걸린 설계 문제는 찾지 못했습니다."

**그런데 여기까지는 아직 '새로운 문제 설정'이지 '이론적 기여'가 아닙니다.**
이걸 스스로 먼저 말하고 다음 논점으로 넘어가는 것이 좋습니다.

## 논점 2 — "그건 새로운 세팅이지 이론이 아니지 않나?" (진짜 기여)

여기가 핵심입니다. **측정 모형을 그대로 전개하면 정보행렬이 닫힌 형태로
떨어진다**는 것부터 보여주십시오.

> "저희 측정 모형은 `y = A(θ)ρ + ε` 이고 `A(θ,ĝ) = g[ĝVᵀ ; −[ĝ]ₓC(θ)]` 입니다.
> 센서 잡음이 힘/토크 블록별로 등방이라는 것만 쓰면, 직교 삼면체에 대해
> 정보행렬이 **정확히**
> ```
>     M(θ) = g² [ (3/σ_f²)·V Vᵀ  +  (2/σ_τ²)·C(θ)ᵀC(θ) ]
> ```
> 로 떨어집니다. `Σ_k ĝ_kĝ_kᵀ = I` 한 줄이면 유도가 끝납니다."

그리고 **이 한 식에서 네 가지가 동시에 나온다**는 것을 보여주는 것이
설득의 전부입니다.

### (1) 기울임 방향은 아무 상관이 없다

> "`M(θ)` 에 `ĝ` 가 남아 있지 않습니다. 직교 삼면체를 쓰는 한 **삼면체를 통째로
> 어떻게 돌려도 정보량이 같습니다.** 그래서 설계공간이 `Θ × SO(3)` 에서 `Θ` 로
> 줄어듭니다. 저희가 형상만 설계하는 것이 임의의 선택이 아니라 **증명된
> 축소**입니다."

### (2) rank 는 절대 4를 못 넘는다 — 그래서 관절이 **필요조건**이다

> "`M(θ) = a·VVᵀ + b·CᵀC` 이고 `C` 는 3×P 이므로 `rank M(θ) ≤ 1 + 3 = 4` 입니다.
> **중력 방향을 몇 개를 쓰든, 몇 번을 반복하든 상관없이 4 입니다.**
>
> 이 말은 곧, **물체가 강체이면 부위 5개 이상은 원리적으로 식별 불가능**하다는
> 뜻입니다. Sum of Its Parts 가 균질 부위 가정과 비음수 제약 같은 **사전지식으로**
> 이 부족분을 메우는 이유가 여기 있습니다. 정보가 없어서 가정으로 메우는 겁니다.
>
> 저희는 관절을 접습니다. 그러면 `C(θ)` 가 바뀌므로 **매 형상마다 새로운 행공간이
> 들어옵니다.** 즉 관절 운동은 '도움이 되는 추가 옵션'이 아니라, 부위가 5개
> 이상인 물체에서 **유일한 정보 채널**입니다. 저희 방법이 관절체에 특화된 것은
> 공학적 선택이 아니라 **정리에서 강제된 것**입니다."

**이 문단이 논문 전체의 정당화입니다.** 여기서 납득이 되면 나머지는 따라옵니다.

### (3) "안 보이는 것"이 무엇인지 완전히 특성화된다

> "영공간도 정확히 나옵니다.
> ```
>     null M(θ) = { u :  Σ_i u_i V_i = 0   그리고   Σ_i u_i V_i c_i(θ) = 0 }
> ```
> 즉 **총질량과 손목 기준 1차 모멘트를 동시에 보존하는 질량 재분배는 보이지
> 않습니다.** 정지 렌치는 질량 분포의 0차·1차 모멘트만 보기 때문입니다.
>
> 이건 저희 알고리즘의 한계가 아니라 **측정 물리의 한계**이고, 그래서 어떤
> 추정기를 써도 안 바뀝니다. 그리고 능동 설계가 하는 일이 정확히 정의됩니다 —
> `θ_1` 에서 숨어 있던 재분배가 `θ_2` 에서 드러나도록, **영공간을 가장 빨리
> 회전시키는 형상을 고르는 것**입니다."

### (4) 왜 폐루프여야 하는지가 나온다

> "그리고 `M(θ)` 에 밀도 `ρ` 가 들어 있지 않습니다. 형상만으로 결정됩니다.
> 그러니 **센서 잡음만 있는 세계라면 최적 형상 수열을 오프라인에서 전부 미리
> 계산할 수 있고, 폐루프가 필요 없습니다.**
>
> 저희가 폐루프를 도는 유일한 이유는, 유효 잡음이
> `R_eff = R_sensor + J(ρ) Σ_θ J(ρ)ᵀ` 이고 여기 `ρ` 가 들어오기 때문입니다.
> **설계 변수 θ 를 오차를 갖고 재기 때문에, 설계가 추정 상태에 의존하게 됩니다.**
> 즉 폐루프는 편의가 아니라 EIV 구조의 필연적 귀결입니다."

## 논점 4 — "그래서 실험이 이걸 어떻게 뒷받침하나?"

**정리 → 예측 → 측정** 의 대응을 표로 보여주는 것이 가장 빠릅니다.

| 정리가 예측하는 것 | 무엇으로 확인하나 |
| --- | --- |
| 삼면체 회전은 정보량을 안 바꾼다 | `study_theory.py` ②, 기존 `study_tilt.py` |
| 단일 형상은 rank ≤ 4 | `study_theory.py` ③④ |
| 전체 식별에 `R ≥ ⌈(P−1)/3⌉` | **2-link 하한 1 = 관측 1, 3-link 하한 2 = 관측 2** ★ |
| rank 4 천장이 실물에서 구속한다 | **3-link 는 미지수 5인데 단일형상 rank 가 4에 걸림** |
| 하한과 실제 사이에 조건수 간극 | **desk lamp 가 2 라운드** (하한은 1) |
| 그 간극은 각도 정밀도가 만든다 | **P=2..8 × rel 2D 스윕** — 벽이 오른쪽으로 밀림 |
| 스캔 메시에서도 성립 | **desk lamp** (분해 실측 GT 396/82/84 g) |
| 야생 물체에서도 성립 | **laptop** (기지 추 50 g 부착 delta 검증) |

> "물체 4개가 전부 다른 것을 검증합니다. 개수를 늘리려고 고른 게 아니라
> **이론의 서로 다른 부분에 대응시켜서** 고른 것입니다."

그리고 P≥5 결과를 **먼저** 꺼내십시오. 숨기면 리뷰어가 찾아냅니다.

> "부위가 6개를 넘으면 12 라운드에도 수렴하지 않습니다. 이건 저희 방법의
> 실패가 아니라 **정리 3이 예측한 조건수 간극을 측정한 값**입니다. 그리고
> `rel` 을 5%에서 1%로 줄이면 벽이 오른쪽으로 밀리므로, **병목이 추정기가
> 아니라 각도 센싱이라는 것이 실험으로 분리됩니다.** 다음 연구의 방향이
> 어디인지까지 이 그림이 말해 줍니다."

## 논점 5 — 예상 반론과 답변

**Q. "블록 등방 잡음 가정은 강한 것 아닌가?"**
> AFT200 은 축별 사양이 힘 3축, 토크 3축으로 각각 같으므로 실제로 성립합니다.
> 다만 `R_eff` 에 각도 항 `JΣ_θJᵀ` 가 더해지면 등방성이 깨집니다. 그래서 정리는
> **센서 잡음에 대해 정확**하고 각도 오차 하에서는 **근사**입니다.
> 논문에 이 구분을 명시하고, `study_theory.py` 로 근사 오차를 수치로 보고합니다.

**Q. "rank 4 한계는 정지(static) 측정이라서 아닌가? 동적으로 흔들면?"**
> 맞습니다. 동적 여기를 쓰면 관성 항이 들어와 더 많은 모멘트를 봅니다.
> **하지만 그것이 바로 저희가 정지 측정을 택한 이유입니다** — 마찰 유지 관절
> 물체를 동적으로 흔들면 관절이 흘러서 `θ` 가 미지수가 되고, 관절 손상 위험도
> 있습니다(Intro 에 이미 쓴 논지). 즉 **"동적 여기를 쓸 수 없는 물체군에서
> 정보를 어떻게 얻는가"** 가 문제 설정이고, 정리 2는 그 제약 하의 정보 상한을
> 정확히 규정합니다. **한계가 아니라 문제 정의입니다.**

**Q. "Sum of Its Parts 와 뭐가 다른가?"**
> 그들은 강체 조립품이라 정리 2.1 에 의해 rank 4 에 갇혀 있고, 그래서 균질
> 부위 가정과 비음수 제약이라는 **사전지식으로** 부족분을 메웁니다.
> 저희는 관절을 접어 **측정으로** 메웁니다. **사전지식 대 측정** — 이게 차이이고,
> 정리 2.1 이 그 차이가 왜 필연인지 설명합니다.

**Q. "부피(스캔) 오차는 어떻게 되나?"**
> 정직하게: 축척 오차는 힘 행(`s³`)과 토크 행(`s⁴`)에 다르게 들어가므로
> 상쇄되지 않고 편향을 만듭니다. 대응은 두 가지 — (a) RGB-D + 기준 마커로
> 축척을 외부에서 주고 Problem Formulation 에 가정으로 명시, (b) 축척 `s` 를
> 파지점 어긋남 `δ` 처럼 미지수로 함께 푸는 방안을 검토 중.
> **도심 오차(5mm → 42%)** 는 축척으로 안 고쳐지므로, custom object 에서
> 스캔 도심 vs CAD 도심을 실측해 정량화하고 민감도 곡선을 한계 섹션에 넣습니다.

## 보고 (지시문 7절)

### ⚠ 표를 읽기 전에 — 표의 숫자는 대부분 '주입한 부피오차' 다

조건 4개에는 부피오차가 항상 들어 있어서, 표 A/B 의 셀이 알고리즘의 실력인지
주입한 오차인지 표만 봐서는 안 갈린다. 그래서 부피오차만 0 으로 둔 진단을
따로 돌렸다 (조건 4개 밖, 같은 하이퍼파라미터, seed 0~4).

| | 2 links | 3 links | 4 links | 5 links | 6 links |
|---|---|---|---|---|---|
| vol 0 % / ang 1 % (진단) | 0.09 ± 0.06 | 0.06 ± 0.03 | 0.11 ± 0.03 | 0.34 ± 0.21 | 0.20 ± 0.08 |
| C0 = vol 1 % / ang 1 % | 0.7 ± 0.3 | 0.9 ± 0.3 | 0.9 ± 0.2 | 1.1 ± 0.2 | 1.2 ± 0.2 |

**파이프라인 자체의 밀도오차는 0.06~0.34 % 로, C0 셀의 1/5~1/10 이다.** 즉
C0 행조차 대부분 1 % 부피오차가 그대로 비친 것이다. 논문에 표 B 를 실을 때
"이 값은 밀도 추정의 정확도가 아니라 **입력 형상 재구성 정확도의 하한**" 이라고
읽어야 한다. (이 진단은 지시문의 조건 목록에 없다. 표 해석에 필요해서 한 줄만
덧붙인 것이며, ablation 으로 확장하지 않았다.)

### 링크 수에 따른 추세

C0 기준 0.7 → 0.9 → 0.9 → 1.1 → 1.2 % 로 **단조 증가하되 매우 완만하다**
(링크당 약 0.1 %p). 특정 N 에서 정확도가 꺾이는 지점은 없다. 꺾이는 것은
정확도가 아니라 **비용**이다 — 종료 반폭이 N=3 의 0.6 % 에서 N=4 에 1.5 %
로 뛰고(NLINK_DIAGNOSIS.md 2절의 "p=3 → p=4 에서 판이 뒤집힌다" 와 같은
자리), 정지까지 쓴 configuration 수가 1.2 → 2.0 → 3.0 → 4.4 → 6.6 으로
늘며, 수렴 실패는 오직 N=6 에서만 나온다.

### C1 vs C2 — 어느 쪽이 더 민감한가

**정확도는 volume 오차가 압도적으로 지배한다.** 5 % 로 올렸을 때 평균 오차가
C1 은 4.3~5.7 % 인데 C2 는 0.7~1.2 % 로, **모든 N 에서 C1/C2 = 4.7~6.0 배**다.
C1 의 값이 주입한 5 % 와 거의 같은 것은 우연이 아니다 — 회귀는 rho 의 계수로
부피를 그대로 쓰므로 부피오차는 회귀행렬의 **열 스케일**이고, 해가 정확히
1/(1+delta) 배로 밀린다 (exp_v2_volume.py 의 재매개화 논증). 이건 잡음이 아니라
치우침이라 **라운드를 늘려도 안 없어진다.**

반대로 angle 오차 5 % 는 점추정을 거의 안 건드린다 (C2 ≈ C0, 차이가 표준편차
안에 든다). 대신 **비용과 수렴으로 나타난다**: N=6 에서 configuration 이
6.6 → 12.6 개로 두 배가 되고, 종료 반폭이 2.5 % → 3.7 % 로 커지며,
수렴 실패 4건이 전부 여기서 나온다. 한 줄로 쓰면 —
**volume 오차는 정확도를, angle 오차는 라운드 수와 정지 가능성을 정한다.**

### 수렴 실패

100 trial 중 4건, **전부 N=6 이고 전부 angle 5 %** 다 (C2 seed 1·2, C3 seed 0·1).
넷 다 14 라운드 예산을 다 쓰고도 목표 반폭 tau=3.0 % 에 못 닿았다 (종료 반폭
3.3~5.8 %).

원인 추정: 추정이 터진 것이 아니라 **불확실성이 예산 안에 안 줄어든 것**이다.
근거는 실패한 trial 의 점오차가 같은 조건에서 수렴한 trial 과 다르지 않다는
것이다 (C2 실패 2건 0.8 / 1.3 % vs C2 전체 평균 1.2 %). NLINK_DIAGNOSIS.md 2절
대로 부위를 가르는 정보는 토크 6행에만 있고 그 자리가 각도오차에 지배되어,
p=6·각도 5 % 에서 유효잡음이 sensor 대비 2.6e4 배가 된다. 반폭은 여전히
1/√R 로 줄지만 14 라운드로는 모자란다. 라운드를 늘리면 도달한다 (같은 문서의
R 스윕). seed 의존성이 큰 것도 이 그림과 맞는다 — seed 마다 링크 길이가 달라
조건수가 달라지고, 같은 C2 안에서 8 라운드에 끝난 seed 4 와 14 라운드로도
못 끝낸 seed 1 이 갈린다.

### 오차 전파 (6링크 C0, L1 vs L6)

L1 1.0 ± 0.1 %, L6 0.8 ± 0.5 %. 링크별로 보면 L1 1.0, L2 1.3, L3 1.0, L4 1.3,
L5 1.6, L6 0.8 로 **말단으로 갈수록 커지는 전파는 안 보인다.** 다만 L6 의
표준편차가 L1 의 5 배라, 말단 링크는 값이 커지는 게 아니라 **seed 마다 더
흔들린다.** 이는 부피오차가 링크마다 독립인 치우침이라 위치와 무관하기
때문으로 보인다 — 전파를 논하려면 부피오차가 없는 조건에서 다시 봐야 한다.
표 게재는 권하지 않는다 (전파 주장을 뒷받침하지도, 반박하지도 못한다).

### 실물 실험과 다르게 설정한 항목

| 항목 | 이 실험 | 실물 실험 |
|---|---|---|
| 물체 | nlink 합성 사슬, 링크 길이를 seed 마다 70~150 mm 에서 무작위 | 2link / 3link / desk lamp (고정 CAD·스캔) |
| GT 밀도 | 5200 → 700 kg/m^3 로그 등간격 | 실물 재료 밀도 |
| trial 수 | seed 5개 (0~4) | seed 8개 (exp_v2_main.py) |
| 부피오차 | **인위적으로 주입** (±1 % / ±5 %) | 주입 없음. 재구성 오차가 있는 그대로 |
| 각도오차 기준값 | 1 % (지시문 임시값) | 저장소·논문 기본값은 5 % → 여기서는 C2/C3 가 그 설정에 해당 |
| 파지점 | 모든 N 에서 link1 몸쪽 끝면 중심 한 곳 | 물체마다 다름 |
| 측정 | Drake 참값 plant + 가우시안 F/T 잡음 | 실제 F/T 센서. 타어링·핸드아이 캘리브레이션·FoundationPose 단계가 앞에 붙는다 |
| 사람 개입 | 없음 (관절각을 그대로 지령) | 사람이 관절을 맞추고 안전 확인 2단 |

같게 유지한 것: 목표 반폭 tau(p) = 0.5 % x p, 최대 14 라운드, 연속최적화
시작점 6개, D-최적, TLS 추정기, residual 정지 규칙, configuration 당 측정
3회(중력 3방향), 힌지를 정지 판단·채점에서 제외. 조건별로 바꾼 하이퍼파라미터는
없다.

# 바뀐 방법론에 맞춘 실험 표 제안

> 지금 논문의 표 I(부피) · 표 II(시뮬 밀도) · 표 III(실물 밀도) · IV-D(자산 검증)를
> "부위당 10개(질량·무게중심·관성)"와 "힌지 제약 여기"에 맞춰 다시 짠다.

## 0. 지표

| 지표 | 정의 | 어디서 정답이 있나 |
|---|---|---|
| 질량 오차 [%] | \|m̂ − m\| / m | 저울 (모든 물체) |
| 무게중심 오차 [mm] | ‖ĉ − c‖ | 균형·매달기 (모든 물체), CAD (3링크) |
| 관성 오차 [%] | ‖Î_c − I_c‖_F / ‖I_c‖_F, 주축 모멘트별 | **CAD 로 만든 3링크만** (E 절 참고) |
| **base parameter 오차** | 식별 가능한 22개 조합(3링크)의 오차. `dynex.identifiability` 가 조합을 준다 | 모든 물체 — 정답 부위값을 조합으로 투영 |
| 보고 반폭 적중률 | 참값이 95 % 구간 안에 든 비율 | 전부 |
| 힌지 안전 | 궤적 중 힌지 축 토크 최대 / 유지토크, 미끄러짐 횟수 | 시뮬 = 계산, 실물 = 카메라 각도 변화 |
| 자산 충실도 | 떨어뜨리기·밀기·넘어뜨리기 재생 궤적 RMSE | 실물 영상 |

> ★ 부위별 질량·무게중심·관성 표는 **사전분포에 의존하는 8개 조합**을 반드시 표시해야
> 한다 (GIVENS_AND_RISKS.md 0절). 순수하게 측정으로 정해지는 것은 base parameter 뿐이다.

## 1. 표 I — 정답(GT) 물체와 측정 방법 (새 표)

물체마다 어떤 정답이 있는지 밝힌다. 관성 정답이 있는 물체와 없는 물체를 섞어
쓰면 리뷰어가 가장 먼저 걸고넘어진다.

| 물체 | 질량 | 무게중심 | 관성 | 힌지 유지토크 |
|---|---|---|---|---|
| 3링크(가루 가득 채움) | 저울 | 균형 + CAD | **CAD** (+ 3선 진자 1부위 검산) | 토크 게이지 |
| 2링크 | 저울 | 균형 + CAD | CAD | 토크 게이지 |
| 스탠드 램프 | 저울(분해) | 매달기 | 없음 | 토크 게이지 |
| 노트북 | 저울 | 매달기 | 없음 | 토크 게이지 |

## 2. 표 II — 시뮬레이션: 무엇이 정확도를 정하는가 (기존 표 II 의 후계)

기존 표 II 의 축(부피 오차 × 각도 오차)을 다음 축으로 바꾼다. 셀 = 부위 평균
질량 / 무게중심 / 관성 오차, 라운드 수, 미끄러짐 횟수.

| 축 | 값 | 무엇을 보이나 |
|---|---|---|
| 힌지 예산 | 0.1 / 0.2 / 0.33 / ∞ N·m | **정보 대 안전의 곡선** ("황금 비율"). ∞ 열에서 미끄러짐이 나타나야 한다 |
| 센서 기록 | 50 Hz Modbus / 200 Hz / 1 kHz(+IMU) | 하드웨어 업그레이드의 가치 |
| 형상 선택 | 정보이득 / 무작위 / 한 형상 고정 | 한 형상 고정 = 강체 방법(Scalable Real2Sim)의 한계: 10P 중 10개만 관측 |
| 참값 변형 | 균일 / 셸 도심 / 삽입 추 | 정적 방법이 못 보는 무게중심·관성을 동적이 잡는가 |
| 툴 오차 | 0 / 2 %·1 mm·5 % | 툴 식별 정밀도 요구치 |
| 시각 어긋남 | 0 / 5 / 20 ms | 동기화 요구치 |

**행 하나는 반드시 "정적 PIVoT"** 이다. 같은 물체·같은 잡음에서 논문의 정적
루프가 주는 질량·(균일가정)관성 오차를 나란히 두어, 동적 여기가 무엇을 더
주는지(무게중심·관성)와 무엇은 더 못 주는지(질량)를 정직하게 보인다.

## 3. 표 III — Baseline 비교 (시뮬 + 실물)

| 방법 | 무엇을 주나 | 관절체에서의 한계 |
|---|---|---|
| PUGS / SiPhy / PhysX-Omni (비전) | 밀도 추정 → 균일가정 관성 | 만지지 않음 |
| **정적 PIVoT** (논문 원안) | 부위 질량, 균일가정 관성 | 무게중심·관성 못 잼 |
| 강체 동적 식별 (Scalable Real2Sim 식, 형상 1개, 힌지 제약 없음) | 조립체 10개 | 부위 분리 불가, 힌지 미끄러짐 |
| 동적 + 형상 다양성, 힌지 제약 없음 | 부위 10개 | 미끄러짐 (표 II ∞ 열) |
| **동적 + 형상 다양성 + 힌지 제약 (제안)** | 부위 10개, 안전 | — |

실물 열은 3링크·2링크에서 질량/무게중심/관성, 램프·노트북에서 질량/무게중심만.

## 4. Ablation (제안 방법 안에서 하나씩 끄기)

| 끄는 것 | 기대 현상 |
|---|---|
| 보수성 k=2 → 0 | 더 빠른 궤적, 미끄러짐 위험 ↑ (시뮬에서 횟수로) |
| 물리 일관성 투영 | 저질량 부위에서 음의 관성 |
| 영점 공유 → 궤적별 영점 | 1차 모멘트 정보 소실 (이번 v1 실행에서 실제로 관측) |
| 정보이득 목적 → 조건수 (Tedrake) | 사전분포 활용 여부 |
| 케이블·작업공간 제약 | 실물에서만 의미 |

## 5. IV-D 자산 검증

정적 원안은 "정지 동치"까지만 검증했다. 동적판은 관성을 재므로 **동적 과제**
(떨어뜨리기, 밀어서 회전, 넘어뜨리기)의 재생 궤적 RMSE 를 정적 자산 / 동적 자산 /
정답 자산 셋으로 비교한다. 여기서 정적 자산과의 차이가 곧 이 논문의 존재 이유다.

## 6. 실물 실험 사다리 (측정 사슬 검증 순서)

1. 빈 툴 여기 궤적 → 툴 10개 (잔차 = 잡음 바닥, 케이블 힘 검출)
2. 아는 강체(질량·무게중심·관성 CAD) → 회수율. 토크 기준점·시각 지연 여기서 식별
3. 3링크(전부 주어짐) → 표 III 실물 열
4. 램프 → 질량·무게중심만
